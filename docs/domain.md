# 科学领域规范

本文是当前科学模型、单位、容差、推导和编辑语义的权威来源。公开算法、格式编解码、Worker 和 viewer 共用这些约定。

需求编号见[产品规范](product.md)，接口边界见[架构](architecture.md)，验收场景和独立参考方法见[质量规范](quality.md)，开发命令见[开发指南](development.md)。

## 结构、身份与单位

### 源结构与派生实例

结构必须明确区分周期晶体与非周期分子；不以“是否碰巧有 lattice 字段”隐式改变同一坐标字段的含义。

- 周期源原子使用显式分数坐标，必须有有效晶胞。非周期源原子使用 Å 制笛卡尔坐标，不自动附加包围盒晶胞。
- 原子和键各有独立、稳定、结构内唯一的 ID。标签允许与元素名不同，不能作为身份；对象引用和数组索引也不能代替 ID。删除后新建原子获得新 ID，undo 恢复原 ID。
- 周期键的每个端点携带源 AtomId、稳定的对称操作 ID 和整数晶胞平移，才能表达非对称单元中原子的非恒等影像；只用 AtomId 加平移不足以表达这类关系。非周期端点使用恒等操作和零平移。所有来源和操作必须存在，两个端点解析到同一规范化实例的自键非法；同一源原子与其不同对称/平移影像之间的周期键允许存在。
- 源原子保存元素、坐标和可选占位、同位素、形式电荷、氧化态、自由基及等方位移等已建模语义。元素的价电子数、氧化态和形式电荷是不同概念；不得沿用旧 `valence` 字段的歧义。
- 显示实例是可重建派生数据，至少能回溯源 AtomId、对称操作和整数晶胞平移，并携带实际显示位置。渲染 mesh、GPU 缓冲及 worker 对象不属于源结构。
- 快照与调用者隔离。派生算法不就地改动源原子、显式键、元数据或调用者传入数组。格式专用文档 AST 不进入科学核心；需要保存原文/未映射类别时，由格式结果单独承载。

### 单位及数值约束

长度为 Å，倒易长度为 Å⁻¹，晶胞输入/输出角度和公开测量角度为度，内部三角函数使用弧度。原子质量单位为 u，占位无量纲，等方位移以 U 的 Å² 值为标准模型表示；B 与 U 的关系为 `B = 8π²U`。

所有参与计算的数值必须有限。晶胞边长大于零，角度位于 `(0°, 180°)`，矩阵必须可逆且右手体积为正。占位数值在 `[0,1]`；未知和不适用是显式状态，不用 `false`、`NaN` 或 0 代替。可选占位未给出时按 1 处理并记录默认来源；显式未知占位不能变成满占位。

以下为不同用途的固定默认容差；API 可暴露具有明确单位的配置，但不能使用一个通用 epsilon 替代全部规则。改变默认值须更新本文件、决策和测试。

| 用途                | 默认规则                                                                                                        |
| ------------------- | --------------------------------------------------------------------------------------------------------------- |
| 数学基准比较        | `abs(actual-reference) <= 1e-9 + 1e-10 * max(abs(actual), abs(reference))`，各量按其声明单位比较。              |
| 源坐标/晶胞正逆变换 | 使用上述数值容差；同时测试按晶胞尺度归一化后的残差，不能仅比较显示舍入值。                                      |
| 对称特殊位置去重    | 同一源原子、同一实际显示位置的分数坐标分量差均不超过 `1e-6`；不按周期取模合并不同邻胞位置。                     |
| 晶胞有效性          | `det(A) > 0`，且 `det(A)/(a*b*c) > 1e-10`；不满足时报退化或病态晶胞错误。                                       |
| 晶格等距/对称校验   | 对晶胞度量矩阵的相对残差不超过 `1e-6`；与实测晶胞舍入精度有关的差异单独诊断。                                   |
| 成键阈值边界        | 距离比较容差 `1e-8 Å`；同一规范化周期原子对只能产生一个推断键。                                                 |
| 配位距离边界        | 显式元素对规则的最小、最大距离均含边界，比较容差 `1e-8 Å`；默认最小距离为 `0 Å`。                               |
| 测量退化判定        | 边长不超过 `1e-9 Å` 时相关角无定义；归一化叉积模不超过 `1e-12` 时二面角无定义。正常角度基准误差不超过 `1e-6°`。 |

括号不确定度是测量信息，不是浮点比较容差。例如 CIF `0.1234(5)` 保存中心值和标准不确定度，不将括号内容丢入 `parseFloat` 后宣称无损。源数值不确定度及原始字面值由相应科学字段/格式结果保存。坐标系转换不能将各分量的不确定度原样复制到新坐标；没有足够协方差信息进行可靠传播时，保留原坐标系的测量信息并诊断导出损失，不能编造新不确定度。坐标或晶胞被编辑后，不能继续声称旧不确定度描述新数值，必须清除受影响字段的不确定度并给出诊断。

## 晶胞、对称、成键与测量

### 晶胞和坐标变换

采用列向量约定：`r = A f`，`f = A⁻¹ r`，其中 `A=[a⃗ b⃗ c⃗]`。常规参数到基矢的唯一实现为：

```text
a⃗ = (a, 0, 0)
b⃗ = (b cos γ, b sin γ, 0)
c⃗ = (c cos β,
      c (cos α - cos β cos γ) / sin γ,
      V / (a b sin γ))
V  = a b c sqrt(1 - cos² α - cos² β - cos² γ
                   + 2 cos α cos β cos γ)
```

公式中的三角函数参数已经转换为弧度。体积以 `det(A)`/等价参数公式推导；文件提供的体积仅作交叉检查，超过输入精度与数值容差时诊断，不用不一致体积继续做坐标变换。退化或病态矩阵报错，不能以零坐标、绝对值开方或默认正交晶胞掩盖错误。

源分数坐标允许在 `[0,1)` 外，不静默改写用户输入。需要单胞代表位置时仅在派生层用 `wrap(f)=f-floor(f)`，保留所减整数平移。邻胞显示不能用逐坐标最短距离代替实际笛卡尔距离；非正交晶胞的最小影像及候选范围必须根据晶胞度量计算。

### 对称、邻胞及 cutoff

对称操作采用仿射表示 `f' = R f + t`，邻胞平移在对称操作后添加：`f_display = R f_source + t + n`。`R` 为晶格上的可逆整数矩阵，行列式为 ±1；`t` 来自精确有理数。格式中的字符串使用限定的仿射语法解析，不交给通用表达式执行器执行任意函数或语句。

显式操作是该结构的实际操作来源。IT 号、H-M/Hall 名称和 setting 分开保存；操作、标识互相冲突时给出诊断，不能仅凭 IT 号套用数组第一项。显式操作缺失且名称/setting 可唯一解析时使用可追溯数据表；存在歧义时保留基础结构并报告待解决的对称信息，拒绝执行猜测的对称扩展。没有任何对称信息的晶体只使用恒等操作，并给出该假设的诊断。

派生顺序如下：

1. 校验操作及选定的整数邻胞列表，移除重复请求，确保中心单胞参与计算。
2. 将每个操作作用于源原子，得到单胞代表；归一化时记录整数平移，再生成请求邻胞中的实际位置，保证最终来源变换可逆且可复核。
3. 同一源原子的特殊位置重合按上表容差合并实例，并保留等价来源列表。不同源 AtomId 即使位置、元素相同也不合并，避免吞掉无序位点或独立占位记录。
4. 使用确定顺序生成实例与派生键；同输入、同配置在同步和 worker 路径下得到相同身份、位置与关联，不依赖并发返回顺序。

fraction cutoff 的配置为三个非负分数宽度 `q`，在请求的候选实例中保留闭区间 `[-qx,1+qx] × [-qy,1+qy] × [-qz,1+qz]` 内位置，边界按去重容差判断。主要单胞归属使用 `[0,1)`，上边界属于相邻单胞；显示裁切可以显示两侧边界实例。

bond cutoff 保留主要单胞中的全部实例，包括孤立原子，并增加与其直接成键的第一层端点；不递归扩展无限连接网络。用于寻找这些端点的邻胞范围由最大成键距离和逆晶胞界限确定，不能固定为 `[-1,1]³`；用户邻胞选择决定允许显示的副本集合。扩大候选范围不得顺便改变源结构或删除孤立原子。

### 键与化学属性

显式键包含来源、键阶和可表达的立体属性；推断键标记为推断结果，不能覆盖显式键阶。默认推断为几何邻接单键，不据此宣称完成价态、芳香性或化学结构识别。

原子`stereoParity`保存odd/even/either及四个有序稳定邻原子引用，至多一个null表示隐式氢；引用必须与实际成键邻居一致。分子`stereoAbsolute`保存CTfile绝对立体标志，不等同于“该分子是手性的”。单键up/down/either相对于有序键端点；MOL双键either表示未指定几何关系，不把该标记解读为cis或trans。文件记录重排必须调整原子parity奇偶，不推断R/S或E/Z；删除参照邻原子时清除并诊断，undo恢复。

V2000 mass difference是相对于格式参考质量数的整数差，不是相对于标准原子量。codec使用固定RDKit2025.09.6参考表（来源/散列/许可随包），例如Br的参考为79而不是round(79.904)=80；输出使用绝对质量数`M ISO`。这张编码参考表不替换core质量/半径表。

默认几何规则为 `0.1 Å < distance <= 1.2 * (r_cov(i)+r_cov(j))`，阈值使用上表边界容差；半径须有可追溯来源、单位和缺失策略。未知/无半径元素不伪造半径，产生不能推断该原子键的诊断。元素对判断对称，不使用旧表单向 `bondElements` 判断输入顺序。

默认采用 Cordero 2008 经 periodictable 2.0.2 发布的共价半径，单位 Å；C 取 sp3，Mn/Fe/Co 取低自旋。1–96 有值，97–118 显式缺失。质量区分标准原子量和明确质量数的代表同位素质量，不将后者称为天然平均原子量。空间群默认数据为 spglib 2.6.0 的 Hall 1–530，IT/H-M/Hall/choice 分别保存；详见[来源台账](data-sources.md)。

范德华显示半径独立采用mendeleev-data1.1.0固定提交的`vdw_radius_alvarez`，主体Alvarez2013，稀有气体按Vogt2014更新；pm除以100转换成Å。94个编纂值中包含估算，不统称实测常数。Pm、Po、At、Fr、Ra及Fm–Og共24元素保持缺失。它不替换上述质量、共价半径或成键规则；缺失时viewer报告诊断并采用可配置的1.5Å视觉兜底，不把该值回写科学数据。源/输出散列及MIT许可见随包`VDW_DATA_MANIFEST.json`与第三方声明。

`applySymmetry?:boolean`默认true；false只选择旋转为恒等、平移为整数晶格平移的真实操作，保留原操作ID及归一化偏移。无法找到恒等操作时返回`SYMMETRY_IDENTITY_REQUIRED`，不修改源对称信息。派生键仍按真实源操作及所保留实例投影，不能按字面`identity`筛选或在renderer重写规则。

周期键的端点是 `(sourceAtomId, symmetryOperationId, integerCellOffset)`。先解析特殊位置的等价实例，再将两端共同减去首端整数平移，比较正反两个方向的端点元组，取确定的规范表示；不能在交换端点时丢失对称操作或平移的符号。候选搜索须覆盖非正交晶胞及跨多晶胞的短距离情况。源结构的显式键和当前规则推断出的其余键可以共同存在，同一规范化端点对以显式记录优先。

空间索引或等价有界邻域算法服务于万级实例场景；不能仅把 O(N²) 代码包装成 async 或 worker 后视为完成性能工作。增删改后的有效结果须与完整重算一致，先保证等价，再选择增量优化。

端点解析可在一次结构验证或显式键投影内建立 AtomId 索引。索引只属于当前输入快照与本次调用，不跨编辑修订缓存；这不改变端点数学、验证、容差、显式键优先级或诊断，也不形成第二份科学实现。

### 超胞与独立缺陷

整数超胞构建接受周期源与三个正安全整数倍数 `n=(nx,ny,nz)`。先使用源的实际对称操作生成完整中心单胞代表，再对每个代表 `f` 和 `0 <= ti < ni` 的整数单胞平移生成新源原子：

```text
A' = [nx a⃗, ny b⃗, nz c⃗]
f' = ((fx+tx)/nx, (fy+ty)/ny, (fz+tz)/nz)
```

输出是具有新晶胞和显式恒等操作的 P1 周期源，体积为原体积的 `nx*ny*nz` 倍。构建使用完整源对称，不受 viewer 的隐藏副本、邻胞或 cutoff 设置影响；`1×1×1` 仍展开真实对称并生成新身份。显示邻胞继续是派生能力，不改变源结构。

同源特殊位置沿用统一去重规则，并保留全部等价来源；不同源的重合站点保留为不同新原子。每个副本获得独立的新 AtomId，可分别删除或替换元素，形成空位或替位；部分、未知或零占位按原字段复制，不随机展开占位或把它当成具体缺陷。已有标签加确定的唯一后缀；标签缺失仍保持缺失，由格式 writer 按其规则处理。

显式键按真实对称轨道及重复单胞完整构建，端点转换为新 AtomId、恒等操作与新晶胞整数平移；跨边界及跨多个旧晶胞的键保留，键阶不变。推断键仍属于派生结果，不写成新的显式源键。无法完整映射端点时整个构建失败。首版不投影周期键的 `stereo`，任何此字段均以 `SUPERCELL_STEREO_UNSUPPORTED` 拒绝构建；周期原子 `stereoParity` 继续按现有仅分子可用的校验规则拒绝。

构建结果的原子映射保存旧源 `BondEndpoint` 与 `equivalentSources`，键映射保存旧源 BondId。`metadata.alchemionSupercell` 记录版本、倍数、旧晶胞、解析后的旧对称操作及映射；已有同名记录作为 `parent` 保留。普通 metadata、provenance 及 `metadata.alchemionFormats` 隔离复制，其中的任意字符串不自动解释为待改写的 ID。

所有新坐标清除原 `coordinateUncertainties` 及字面值并警告；倍数改变基矢时清除 `cell.parameterUncertainties` 并警告，`1×1×1` 保留未变晶胞的测量。占位、等方 U、氧化态等与坐标无关的科学字段保持原义。保留的旧格式测量仍是来源信息，旧原子 ID 或旧晶胞锚点不匹配时，不能用于当前坐标或晶胞输出。

单次最多构造 100,000 个重复单胞及 100,000 个输出原子，乘积与平移必须处于安全整数范围；非法输入、溢出、预算耗尽或科学映射失败不提交部分结果。纯函数返回与调用者隔离的新快照；编辑命令把构建作为当前文档的一次事务。独立验证场景为 T-DOM-07。

### 几何配位与多面体

配位分析接受显式中心 AtomId 集合及元素对距离规则。中心 ID 去重并按稳定顺序处理；每个源只取完整对称中心单胞中按现有实例 ID 排序的首个代表，返回其具体来源和位置。该代表不随点击影像、当前显示邻胞或裁切改变。缺失中心 ID 报错，不悄悄缩小集合。

每个规则是无序元素对、可选最小距离及必需最大距离，单位均为 Å。元素必须已知，`0 <= minimum <= maximum` 且 `maximum > 0`，所有数值有限；同一无序元素对不能重复配置。最小距离默认 `0`，上下界按上表容差包含；未配置的元素对不产生邻居，不借用共价半径或自动成键结果。空中心集合返回空结果，空规则返回各中心的空邻域。

周期搜索展开完整源对称，并根据 `|Δf_i| <= ||row_i(A^-1)|| * D` 确定平移范围，`D` 为规则最大距离加比较容差；随后使用笛卡尔空间桶和实际距离筛选。不能固定为 `[-1,1]³`，也不使用逐分数分量最小影像。分子只搜索有限原子。候选特殊位置复用实例的统一合并规则，不随中心数重复计入候选预算。

计数是站点记录的几何配位数：只排除中心源的同一实际位置；同源不同平移影像可以分别计数，不同源的重合站点也分别计数。计数不按占位加权，包含仍存在于源中的零占位记录；邻居保留完整来源、实际位置和距离，消费者可另按源占位解释。这不是键级、价态或占位平均配位的推断。

多面体为邻居中心的三维凸包。几何重合点可合成一个顶点，`vertexNeighborIndices` 保留该顶点对应的全部邻居下标，不能据此减少配位数。面从外看逆时针，三角化用于显示；顶点为 Å 笛卡尔坐标，体积为 Å³。计算按最大邻居半径 `r` 归一化，使用 `max(1e-12,1e-9 Å/r)` 的接近与退化阈值，并合并共面三角面。不足四个非共面位置、共线/共面或未形成有效闭合体时，不返回多面体，仍保留有效邻居和配位数并给出 `COORDINATION_POLYHEDRON_DEGENERATE` 信息诊断。

单次搜索最多生成 100,000 个去重后的唯一候选影像；另以 5,000,000 个待枚举格点限制病态搜索，后者是独立搜索预算，不是源原子数与中心数的比较次数。预算或数值范围失败时返回错误，不把截断邻域当作完整结果。凸包体积从归一化值逐维缩放回 Å³，避免先计算 `r³` 造成中间溢出；真实体积仍超出有限正数范围时以 `COORDINATION_VOLUME_RANGE` 失败，不输出 Infinity，也不误报几何退化。浏览器配位任务沿用请求、文档和修订校验、取消及 latest-wins；源修订后旧结果失效。独立验证场景为 T-DOM-08。

### 点坐标和测量

测量输入是用户按顺序点中的显示实例位置，以其实际 Å 笛卡尔坐标计算。不能将跨邻胞选点偷偷缩回最小影像。坐标结果明确标识 `fractional` 或 `cartesian`；非周期结构不返回伪分数坐标。

viewer的自由点坐标与原子中心测量分开：点击原子/键返回表面交点，点击空白返回经过相机target且法向沿视线的视平面交点；事件以`surface/view-plane`说明来源。分数坐标只调用本核心逆转换。每次结构修订清空测量，仍有效的稳定实例选择可重新解析；无效实例必须清理。倒易几何的Å⁻¹坐标在独立视窗中解释，不与Å直接空间混合。

- 距离为 `|r2-r1|`，单位 Å；两个相同位置的点得到 0。
- 角度以中间点为顶点，范围 `[0°,180°]`；用稳定的向量方法并处理舍入，零长边返回无定义诊断。
- 二面角按选点 `A-B-C-D` 定义。令 `b1=B-A`、`b2=C-B`、`b3=D-C`、`n1=b1×b2`、`n2=b2×b3`，结果为 `atan2((n1×n2)·unit(b2), n1·n2)`，单位度，规范化到 `(-180°,180°]`。零长中间边或任一共线法向量返回无定义诊断，不返回 NaN。

## 倒易晶格与第一布里渊区

倒易基矢采用 `B = 2π (A⁻¹)ᵀ`，因此 `AᵀB = 2πI`；这是公开数学约定，不提供同名但省略 2π 的混合结果。倒易坐标是 `k = B h`，单位 Å⁻¹，直接晶格和倒易晶格在各自坐标系中解释。

第一布里渊区是倒易晶格原点的 Wigner–Seitz 胞，定义为所有非零倒易格矢 `G` 的半空间交：`k·G <= |G|²/2`。算法输出顶点、面及可用于显示的三角化结果；三角化仅服务渲染，不改变科学多面体的面关系。

不能固定检查 26 个邻居后无条件返回。采用逐层扩大整数格矢候选的策略，并证明遗漏候选不能裁切当前多面体：若当前顶点最大半径为 `rmax`，未枚举格矢长度的下界大于 `2*rmax`，即可停止；可用倒易矩阵最小奇异值与枚举壳层界给出该下界。达到明确资源预算仍未证明完备时，返回不收敛/预算错误，不输出未标记的近似 BZ。

生产实现使用六个 ±基矢半空间建立有界初始多面体，再增量裁剪。枚举完第 m 壳后，遗漏格矢长度下界使用 `(m+1)/||B⁻¹||F` 并扣除数值裕量；默认最多 64 壳、250,000 个候选，可由调用者配置。独立参考采用 SVD 下界与 Qhull Voronoi，避免用生产裁剪算法生成预期。

验收包括简单立方的解析立方体、正交异长晶胞、非正交晶胞；检查每个顶点满足半空间、相反面/中心对称、面定向和体积 `abs(det(B))=(2π)³/V`。独立参考不得调用生产 BZ 算法生成自身预期值。

## 编辑事务、历史与运行时语义

纯`DocumentStore`拥有源快照与历史，浏览器控制器组合计算运行时，viewer再组合三维显示；各层使用同一套命令、校验和身份规则。

格式来源中的未映射科学语义随`metadata.alchemionFormats`的版本清单保留，不能因一次编辑消失。CIF分量缺失或第二坐标系的不确定度作为格式来源测量保留，包含原坐标和晶胞锚点；锚点不匹配时不能再当作当前测量输出，也不能将缺失分量补为0。完整三分量测量仍使用已有core字段。

- 支持增加/删除源原子、改变元素、改变坐标、改变晶胞；编辑命令使用稳定 ID 和显式坐标系。周期命令的标准输入为分数坐标；界面允许输入 Å 笛卡尔坐标时先按当前晶胞转换，不能靠结构类别猜同一数组的含义。
- 晶胞编辑保留所有源分数坐标，重新推导体积、笛卡尔位置、倒易/BZ、成键和实例。操作若导致晶胞或显式对称不再有效则整个事务失败；用户可在同一事务中显式改为合适对称，不能暗中更换空间群。
- 对派生实例输入新的显示位置时，先将笛卡尔位置转为分数，再使用 `R⁻¹(f_display-t-n)` 回写源原子。改元素作用于源原子；删除作用于源原子及全部副本，并清理关联显式键。
- 批量编辑先在隔离草稿中应用全部命令，再整体校验并提交一次；中途失败不改变源结构、不新增历史、不发布半成品。无实际变化的命令不新增历史。
- 超胞构建在当前文档提交一次，保留 documentId 并递增 revision；undo 恢复原结构，redo 恢复已经分配的超胞 ID。文档内已发出的 AtomId/BondId 及构建分配序号不随 undo 回退，撤销后重新构建必须获得新 ID；load/clear 重新建立或清空文档身份与分配状态。
- undo 恢复该事务前的源结构和稳定 ID；redo 恢复事务后状态。新事务提交后清空 redo。历史默认保留 100 个事务，可配置；限制按完整事务淘汰，不切断一次操作。历史保存领域变更或共享快照，不保存 GPU/worker 状态。
- 每次成功提交、undo、redo 都生成递增的结构修订；undo 不把 revision 倒退。load 在解析及结构校验成功后提交新源，产生新 documentId、清空历史/选择/测量并取消旧文档任务。提交前的解析或结构校验失败保留原文档和历史；提交后的派生/渲染失败保留有效的新源，进入可恢复的 error 状态并拒绝 load Promise，不能误报 ready 或暗中回滚。
- 选择与测量引用失效实例时清理相关结果并通知消费者，不能继续显示来自旧修订的数字。仍有效的源选择可重新解析到新实例，具体展示行为由 viewer 契约定义。
- 异步派生结果须同时匹配请求、documentId 和 revision。过期结果不得提交；被取消、超时或销毁的请求必须结束其 Promise。结构命令串行并保持事务顺序，同类昂贵派生任务采用 latest-wins；取消不等于回滚已成功提交的源事务。
- 主动cancel同时失效尚未接受的命令与当前任务，未完成Promise以AbortError结束；已接受源、稳定ID、历史、documentId/revision保留。状态明确为cancelled且清除失效显示，不发布ready或错误回滚。空闲/重复/销毁后取消幂等；recompute使用同一源与选项，不增加历史和修订，完整帧提交后恢复ready。

## 诊断、参考与验收依据

诊断具有稳定代码、严重级别、可读说明及可定位上下文；格式诊断携带 block/标签/记录和可用的行列，科学诊断携带相关 ID/字段，异步诊断携带任务上下文。分为阻止该操作的 error、结果可用但有明确损失/假设的 warning，以及默认/归一化等 info。不可表示的科学语义默认阻止导出，调用者显式接受后降为带说明的损失警告。

标准依据为 [IUCr CIF 规范](https://www.iucr.org/what-we-do/digital-standards/cif/specification)、[BIOVIA CTfile Formats 2020](https://discover.3ds.com/sites/default/files/2020-08/biovia_ctfileformats_2020.pdf) 和 [VASP POSCAR 说明](https://vasp.at/wiki/POSCAR)。这些规范决定文件规则；本项目的数值容差、默认成键和编辑策略由本文件定义。数据来源、待核实项见 [数据来源台账](data-sources.md)。

科学参考与生产实现保持独立：晶胞和坐标使用解析解与独立矩阵计算；对称使用经核对的操作/特殊位置样例；成键使用枚举的小体系真值；测量使用明确坐标的解析角度；倒易/BZ 使用解析胞及独立半空间/Voronoi 参考。参考生成程序、版本、输入、预期值和来源随可复用测试资产维护，不能从待测函数复制输出当 golden。

文件验收除SDK自身往返外，还使用独立格式工具核验；科学字段按本规范比较，原文字符相同不是结构读写的完成标准。独立方法和固定环境见[质量规范](quality.md)，相关场景为T-DOM-01–08、T-FMT-01–04、T-RUN-01、T-EDIT-01和T-DATA-01。
