## 验收条件与实施步骤

1. 根据周期几何生成间隙候选，展示位置、最近邻距离及去重结果。明确适用的候选规则和搜索预算，由用户确认要插入的元素与位置。
2. 对指定母体元素或选区按数量或浓度生成替位，显示候选位点数、整数取整规则、实际组分及随机种子。
3. 定义部分占位的同位点互斥和配额规则。显式化的构型使用确定的元素／空位结果，保存种子、实际组分及源位点映射。未知占位、冲突和无法满足的配额有明确诊断。
4. 工作台预览后一次提交，可撤销并恢复源结构。用已知晶体的间隙位置、固定种子的批量替位和含互斥位点的 CIF 验证候选、配额、周期去重及导出结果。
