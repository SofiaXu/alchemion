# 粗粒化珠子与介观组装

状态：未开始。需求与验证：尚无稳定 R/T 编号，先定义珠子模型和验收口径。

## 需求与当前事实

[纳米结构](../../api/modeling.md#缺陷分子和有限构型)已通过现有原子结构表达。珠子需要类型、质量、位置、连接及源原子映射的独立表示，现有 CIF、MOL 和 POSCAR 字段面向原子结构。

## 验收条件与实施步骤

1. 定义珠子类型、质量、坐标系、周期边界、连接和来源。明确以指定原子组、片段或聚合物单元进行映射时的分区与质量守恒规则。
2. 用珠子模板构建珠链、层状结构及明确的初始组装几何。验证中心、质量、拓扑、周期接缝与来源，给出预算和诊断。
3. 确定珠子模型的公开入口、工作台预览与版本化交换格式。用可手算的组装夹具和相应浏览器路径验证。

## 进展与续接

从纳米与介观计划迁出。下一步是定珠子及来源模型，准备一个可手算质量与质心的分组夹具。
