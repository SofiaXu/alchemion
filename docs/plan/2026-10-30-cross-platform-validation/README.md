# 工具链升级后跨平台验证

状态：未开始。需求：R-019、R-020、R-023。验证：T-PKG-01、T-DEMO-01、T-VIEW-01–03、T-RUN-01。

## 需求与当前事实

Node26/pnpm12/TypeScript7/Vite8 等工具链升级后，Windows 已有本地验收；升级后的 Ubuntu CI、macOS 和真实 Safari 尚未执行。旧工具链 Linux 结果不能替代升级后的验证；Playwright WebKit 不能替代真实 Safari。

## 验收条件与实施步骤

1. 固定同一提交、锁文件和被测 tarball，记录系统、工具、浏览器和 WebGL2/驱动环境。
2. 使用唯一 delivery 工作流补充 Ubuntu 冻结安装、构建/类型与受影响的浏览器和真实消费者验证，软件渲染明确标记为功能结果。
3. 在 macOS 验证冻结安装（含 fsevents 安装策略）、生产构建、开发 Worker 与真实包消费者。
4. 在真实 Safari 记录版本，走通导入、显示/拾取、编辑历史、取消恢复、格式导出及资源释放；不能仅用 WebKit 自动化结果替代。
5. 逐环境记录通过、失败、未运行项及限制，必要修复另按影响范围处理。日志放忽略目录或 CI 附件，稳定的支持边界写回正式文档。

不把缺少设备标成通过，不从功能验证推导新硬件性能结论。本任务不包含 npm 或站点发布。
