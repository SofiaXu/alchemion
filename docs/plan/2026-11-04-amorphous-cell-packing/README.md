# 非晶胞与分子填充

状态：未开始。需求与验证：新增几何填充需求，复用 R-007、R-019、R-020 的几何与运行时，沿用 T-DOM-01、T-RUN-01、T-EDIT-01、T-DEMO-01，新增组成、密度与周期接触用例。

## 需求与当前事实

现有周期模型和分子模型可以分别导入。缺少按组成和目标密度将溶剂、盐或聚合物链填入周期盒的工具，也缺少在已有基底的限定区域填充溶剂。计划范围为带几何接触检查的初始构型，对照独立模块 [BIOVIA Amorphous Cell](https://www.3ds.com/assets/invest/2023-10/biovia-material-studio-amorphous-cell.pdf) 的构建和填充任务。

## 验收条件与实施步骤

1. 定义组成、分子数或比例、目标密度与晶胞之间的关系。预览有效体积、实际分子数和密度，明确密度与盒尺寸冲突、未知质量和不可达配额的诊断。
2. 将输入分子按刚体或明确的初始构象放置，保留分子内部显式键及来源。按周期度量检查最小接触距离，提供固定种子、搜索预算、取消和填充失败诊断。
3. 支持在已有晶胞的限定区域填充，使用[薄层](../2026-11-04-surface-slab-builder/README.md)作为表面溶剂夹具。[聚合物构建](../2026-11-04-polymer-builder/README.md)可以提供链输入，已导入的分子也可直接填充。
4. 独立核对正交及斜胞的质量密度、配额和周期最小距离，用带基底的填充夹具检查区域边界。浏览器验证取消、过期结果、失败保留原文档和成功一次提交。

## 进展与续接

缺口已登记，功能验证未运行。下一步是确定密度、区域和距离语义，准备含两种分子的小盒及无法填充的反例。
