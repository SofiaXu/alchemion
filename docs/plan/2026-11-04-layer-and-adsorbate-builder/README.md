# 叠层界面与吸附构型放置

状态：未开始。需求与验证：新增结构拼装需求，扩展 R-017、R-020、R-025 的编辑路径，沿用 T-DOM-01、T-DOM-06、T-EDIT-01、T-DEMO-01，新增界面与刚体放置用例。

## 需求与当前事实

工作台已有单结构批量平移。缺少将两个表面合并为共享面内周期的界面，以及将整个分子导入并刚体放置到指定表面位置的工具。界面需显示晶格失配与应变，吸附放置需控制位置、取向和高度。对照 [BIOVIA Visualizer 的层构建与分子操作工具](https://www.3ds.com/fileadmin/PRODUCTS-SERVICES/BIOVIA/PDF/materials-studio-visualizer.pdf)。

## 验收条件与实施步骤

1. 用[矩阵超胞](../2026-11-04-matrix-supercells/README.md)和[晶面薄层](../2026-11-04-surface-slab-builder/README.md)的面内基矢，按给定的旋转、失配上限和搜索预算列出可匹配的面内周期。明确参考层、应变分配及候选面积。
2. 选择匹配后设置相对平移、旋转、层间距及真空，生成共享周期的结构。预览重叠、原子数和组分，保留各输入的来源与可保留的显式键。
3. 从已有分子快照放置吸附物，允许选择分子锚点和表面目标点，按指定旋转及高度定位，保持分子内部几何与显式键。界面合并和吸附放置各可一次撤销。
4. 用已知匹配的同质双层、存在小失配的异质双层和已知变换的分子夹具验证面积、应变、间距、映射、重叠诊断及导出。能量排序的范围见[吸附位点能量搜索评估](../2026-11-04-adsorption-site-search/README.md)。
