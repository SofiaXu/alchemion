# 吸附位点能量搜索评估

状态：未开始。需求与验证：无现行 R/T 编号。目的为记录竞品模拟能力差距并评估是否扩展产品范围。

## 需求与当前事实

[叠层与吸附放置](../2026-11-04-layer-and-adsorbate-builder/README.md)的目标是生成指定几何的吸附初始构型。Materials Studio 的 Adsorption Locator 可对基底与吸附物的构型进行能量搜索，给出低能候选。Alchemion 的现行范围排除量子化学计算和力场优化。见 [BIOVIA Adsorption Locator](https://www.3ds.com/assets/invest/2023-10/biovia-materials-studio-adsorption-locator.pdf) 和[产品边界](../../product.md#产品定位与交付边界)。

## 验收条件与实施步骤

1. 以吸附初始构型为输入，明确待评估的产出为候选构型、使用的能量模型、能量排序及搜索范围。区分几何候选与有模型依据的能量排序。
2. 评估外部计算结果的交换与导入、独立能量搜索模块所需的运行环境、可复现性和验证成本。记录与现行 SDK 边界的关系。
3. 产出是否立项的决定。若后续明确授权扩展范围，再定义对照体系、参考能量、收敛条件和实际实现验收。
