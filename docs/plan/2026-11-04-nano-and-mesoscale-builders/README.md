# 纳米与介观构建

状态：未开始。需求与验证：新增纳米结构与介观结构需求，复用 R-007、R-019、R-020，沿用 T-DOM-01、T-DOM-06、T-RUN-01、T-DEMO-01，新增纳米几何和粗粒化用例。

## 需求与当前事实

现有 SDK 提供周期和非周期原子结构。缺少参数化单壁／多壁纳米管、从晶体裁出有限纳米团簇、将分子映射成粗粒化珠子，以及以珠子组装介观结构的工具。珠子类型、连接、来源与导出需要单独定义。对照 [BIOVIA Visualizer 的纳米、介观与粗粒化工具](https://www.3ds.com/fileadmin/PRODUCTS-SERVICES/BIOVIA/PDF/materials-studio-visualizer.pdf)。

## 验收条件与实施步骤

1. 定义纳米管的材料、手性、直径、长度、壁数、层间距及有限或周期边界语义。多壁的周期兼容性和不可表示输入应有诊断。
2. 从体相选定中心和裁切几何，输出有限纳米团簇及源位点映射，保留内部显式键并报告边缘截断。对照已知纳米管的直径、重复长度与接缝，以及小团簇的解析计数与组成。
3. 明确粗粒化珠子的类型、质量、位置、连接和源原子映射，定义按片段或重复单元进行分组的规则。根据指定形状与组装参数生成介观模型，例如珠链、层状结构或胶束初始构型。
4. 用可手算的原子组和珠链验证映射、质量与连接，用已知组装几何检查占据范围、周期边界及来源。确定格式和公开 API 能表达的介观语义后，再定义工作台及导出验收。

## 进展与续接

缺口已登记，功能验证未运行。下一步是先确定纳米管与团簇的几何契约，再决定珠子模型的边界及介观部分是否独立立项。
