# 性能采集器中文电源名称编码

状态：未开始。维护目的：保持 T-PERF-01 环境记录可读且可复核。

## 需求与当前事实

2026-10-30 Windows 验收中，采集器通过 Windows PowerShell 取得的中文电源名称出现乱码，电源 GUID 可读；同 GUID 的 UTF-8 补充快照显示名称为“平衡”。CIM 电源查询在该会话环境中失败。该问题不影响已记录的科学或 renderer 数值，但应修复环境采集的文本链路。

## 验收条件与实施步骤

1. 定位 `scripts/viewer-bench.mjs` 中 PowerShell → 标准输出 → Node JSON 的编码边界。
2. 使用明确的 UTF-8 传输方式，保留原电源 GUID、查询失败和缺少电池等状态；不通过删除中文或硬编码名称掩盖问题。
3. 在中文 Windows 对照 `powercfg /getactivescheme`，验证 GUID 一致、中文可读、JSON 可解析；对英文输出和查询失败路径做定向验证。
4. 单独采集环境即可验证编码；不为此重复硬件六轮，也不改变性能采样口径。
