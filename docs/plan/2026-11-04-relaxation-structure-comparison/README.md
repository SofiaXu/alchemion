## 验收条件与实施步骤

1. 选择参考和目标帧，预览已匹配、未匹配或存在歧义的原子。非周期结构可用匹配原子做刚体拟合。周期结构明确基矢、原点、周期影像及有晶胞变化时使用的参考坐标系。
2. 两份结构使用可区分的颜色和透明度，显示对应原子的位移箭头、位移值和匹配集合的 RMSD。对晶胞改变分别报告基矢、角度和体积的变化，标明是否扣除均匀晶胞变形后再计算原子位移。
3. 用已知平移与旋转的分子、跨边界的斜晶胞原子和已知变形的晶胞核对配准、位移、RMSD 和晶胞差异。浏览器检查对比开关、按匹配项拾取及图层导出。
