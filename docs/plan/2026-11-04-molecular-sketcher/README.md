# 分子草绘与片段拼装

状态：未开始。需求与验证：扩展 R-009、R-017、R-018、R-020 的分子编辑，沿用 T-DOM-03、T-EDIT-01、T-FMT-02、T-DEMO-01，新增化学编辑用例。

## 需求与当前事实

现有 SDK 支持显式键的结构表示及 MOL 读写，几何推断只产生派生键。工作台可按坐标新增原子，缺少从空白草绘、交互连接原子、改变键阶、插入片段与自动补氢的工具。对照 [BIOVIA Visualizer 的分子草绘工具](https://www.3ds.com/fileadmin/PRODUCTS-SERVICES/BIOVIA/PDF/materials-studio-visualizer.pdf) 和[现有编辑命令](../../api/core.md#同步编辑事务与历史)。

## 验收条件与实施步骤

1. 扩展分子编辑事务，支持添加、删除显式键及改变键阶，处理重复端点、源 ID、立体参照失效与可撤销行为。保持显式键和几何推断键的区分。
2. 工作台可新建分子，通过选点创建原子与连接、选择并修改键阶。定义片段库和自定义片段的连接点、对齐与连接规则，允许预览后一次插入。
3. 定义可支持的元素、价态、形式电荷及芳香键语义，按明确规则补氢。对规则覆盖之外的状态或歧义给出诊断，保留已有显式氢和立体信息。
4. 用中性、带电及芳香分子夹具核对键阶、补氢数量、连接方向、MOL 往返和撤销。整分子在晶面上的放置由[叠层与吸附放置](../2026-11-04-layer-and-adsorbate-builder/README.md)承接。
