# 轨迹播放与反应路径

状态：未开始。需求与验证：新增优化轨迹、分子动力学及反应路径显示，复用 R-007、R-014、R-019、R-020，沿用 T-DOM-01、T-DOM-06、T-FMT-04、T-RUN-01、T-DEMO-01，新增逐帧结构与曲线联动用例。

## 需求与当前事实

当前工作台每次打开一个源结构。缺少将优化过程、MD 轨迹或 NEB 反应路径按帧浏览，并同步显示能量变化和当前结构的功能。复用[结果导入和结构帧](../2026-11-04-calculation-result-import/README.md)与[图层生命周期](../2026-11-04-calculation-result-layers/README.md)。见 [VASP 输出文件](https://vasp.at/wiki/index.php/Category%3AOutput_Files)和 [VASP NEB](https://vasp.at/wiki/index.php/NEB)。

## 验收条件与实施步骤

1. 导入 `XDATCAR` 或 `vasprun.xml` 的已验证轨迹子集，以及本地选择的 NEB 图像及能量。保存每帧坐标和对应晶胞、原子映射与可知的能量。区分优化步、MD 时间及路径图像索引或反应坐标，缺少物理时间或能量时显示可用字段。
2. 提供帧步进、拖动、播放／暂停和速率控制。周期轨迹提供折回与连续显示模式，定义变胞下的跨周期展开与歧义诊断。帧切换与结构编辑历史分开。
3. 能量曲线与当前结构双向联动。切帧时通过结果和帧标识同步标量、矢量或网格图层，缺少同帧数据时标明状态。按预算读入和缓存大轨迹。
4. 用已知跨周期位移、变胞优化及带已知能量的 NEB 图像验证帧索引、晶胞、展开与曲线联动。浏览器检查快速拖动、播放取消、图层失配和资源回收。
