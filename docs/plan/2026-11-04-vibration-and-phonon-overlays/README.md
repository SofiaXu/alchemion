## 需求与当前事实

当前可查看结构与布里渊区，缺少导入分子振动或晶体声子结果、以箭头或动画显示模式，并与频谱或色散图联动的工具。依赖[结构配准](../2026-11-04-calculation-result-import/README.md)和[结果图层](../2026-11-04-calculation-result-layers/README.md)。见 [VASP 声子模式](https://vasp.at/wiki/Phonons_from_finite_differences)和 [BIOVIA Visualizer 的振动分析](https://www.3ds.com/fileadmin/PRODUCTS-SERVICES/BIOVIA/PDF/materials-studio-visualizer.pdf)。

## 验收条件与实施步骤

1. 导入已计算的模式频率及对应原子的本征位移，记录单位、质量归一化约定、虚频状态、参考结构与晶体 q 点。首个验收覆盖可独立复核的分子或 Γ 点模式。
2. 支持模式选择、位移箭头、振幅控制、相位推进和播放暂停。图表中的频率或色散点与对应模式联动。虚频明确标识，若演示位移则注明动画的显示约定。
3. 扩展到非 Γ 点时定义复数本征矢相位与超胞平移的关系，核对可显示的周期范围。使用[超胞](../2026-11-04-matrix-supercells/README.md)的来源映射把位移关联到正确副本。
4. 用双原子模式及已知 q 点相位关系核对箭头、振幅、频率单位和原子索引。浏览器检查模式切换、频谱联动和动画停止后的参考结构显示。
