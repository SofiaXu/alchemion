# 晶面切割与真空薄层

状态：未开始。需求与验证：新增表面建模需求，复用 R-007、R-012、R-026 的几何，沿用 T-DOM-01、T-DOM-05、T-DOM-07、T-EDIT-01、T-DEMO-01，新增晶面与终止层用例。

## 需求与当前事实

工作台可编辑已有晶胞和生成超胞。缺少从体相按 Miller 指数 `(hkl)` 解理并输出带真空的周期薄层。目标是可独立编辑和导出的结构，便于后续叠层、放置吸附分子或固定底层。对照 [BIOVIA Visualizer 的表面构建工具](https://www.3ds.com/fileadmin/PRODUCTS-SERVICES/BIOVIA/PDF/materials-studio-visualizer.pdf)。

## 验收条件与实施步骤

1. 依赖[整数矩阵超胞](../2026-11-04-matrix-supercells/README.md)的基变换。复用倒易基矢确定晶面法向和面内周期，定义零指数、非原始指数及正负方向的处理。
2. 允许选择表面终止、薄层厚度和真空厚度，明确层数与 Å 厚度的换算、边界位点归属及原子数。预览上下表面组分和所得晶胞。
3. 输出可独立编辑的周期快照，保留源位点映射和有效的面内跨边界键。对被切断的显式键、重叠、退化和不可保留的字段给出诊断。构建一次提交并支持现有几何范围的 POSCAR 导出。
4. 对照立方 `(100)`／`(111)` 和非正交晶胞的解析法向与层距，验证不同终止、边界位点、真空厚度及面内周期性。用 demo 检查从体相导入到 slab 导出和撤销。
