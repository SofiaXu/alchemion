# 整数矩阵超胞

状态：未开始。需求与验证：扩展 R-026，沿用 T-DOM-01、T-DOM-07、T-EDIT-01、T-DEMO-01，新增非对角矩阵用例。

## 需求与当前事实

现有超胞接受沿 `a/b/c` 的三个正整数倍数并生成有来源映射的真实 P1 快照。缺少通过非对角整数矩阵重定向基矢并生成超胞的功能。晶面和界面工具需要共享这套晶格变换。当前契约见[超胞 API](../../api/core.md#超胞与配位分析)。

## 验收条件与实施步骤

1. 明确列向量矩阵约定，例如 `A′ = A M`，并定义支持的整数范围、右手性、行列式及资源上限。以 `Z³ / M Z³` 的代表生成原子，原子数和体积按行列式核对。
2. 复用现有源对称展开、超胞 ID 分配、来源记录和显式键映射。为斜变换转换周期键端点及整胞偏移，对无法可靠转换的科学字段返回诊断。
3. 保持现有三个倍数入口的结果和事务语义。工作台可输入矩阵、预览基矢及原子数，成功应用一次可撤销。
4. 对照手算斜胞和独立陪集枚举验证体积、坐标、跨边界键与稳定来源，覆盖奇异矩阵、方向限制、溢出、预算失败和对角矩阵回归。
