# 计算结果格式变体

状态：未开始。需求与验证：扩展 R-036、R-039、R-042、R-043，使用 T-RESULT-01 与 T-RESULT-04。

## 需求与当前事实

[结果格式契约](../../api/formats.md#计算结果读入)列出了已验证的 VASP 与 Cube 子集。现有版本化结果可承载非 Γ 模式和完整周期三维 k 网格。后续可增加非共线 CHGCAR 自旋通道、多帧 CHG、多通道 LOCPOT、多数据集 Cube，以及非 Γ 声子与三维 k 网格的原生读取。

## 验收条件与实施步骤

1. 优先选一个实际使用的格式变体，固定可再分发的真实输出及独立读取参考。明确帧、原子顺序、单位、网格、通道和基底。
2. 通过现有结果模型导入。验证兼容格式、异常或截断输入、单位与帧关联，再用定向工作台场景核对显示。
3. 同步公开格式边界、样例来源和验证记录。
