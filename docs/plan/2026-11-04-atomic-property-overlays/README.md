## 需求与当前事实

当前配色按元素，选择集合可回溯源原子。缺少把计算出的电荷、磁矩或力绑定到原子并叠加显示的工具。依赖[结果原子映射](../2026-11-04-calculation-result-import/README.md)和[图层管理](../2026-11-04-calculation-result-layers/README.md)。VASP 输入来源包括明确输出对应属性的 `OUTCAR` 或 `vasprun.xml`。见 [VASP OUTCAR](https://vasp.at/wiki/OUTCAR)和 [VASP vasprun.xml](https://vasp.at/wiki/Vasprun.xml)。

## 验收条件与实施步骤

1. 定义属性物理量、计算方法、单位、参考方向、帧和源原子。区分不同定义的逐原子电荷、标量磁矩和矢量磁矩，明确缺失值与零值。选择具有对应属性和结构记录的文件子集实现解析。
2. 支持按标量或矢量大小着色，按原子标注和拾取数值，按元素或选区筛选。用可设比例尺的箭头显示力和矢量磁矩，注明物理单位与显示比例。
3. 明确属性在周期平移、对称实例、旋转及变胞下的显示规则。正确区分极矢量和轴矢量的变换，缺少可靠来源或不支持的映射时诊断。
4. 用已知电荷、力和磁矩的小结构核对映射、单位、方向与幅值，覆盖元素重排、跨帧错配、缺失值、选区和矢量对称变换。浏览器检查色标、箭头拾取和导出。
