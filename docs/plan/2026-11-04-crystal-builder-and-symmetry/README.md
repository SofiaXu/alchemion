# 晶体创建与对称识别

状态：未开始。需求与验证：扩展 R-007、R-008、R-017、R-020 的工作流，沿用 T-DOM-01、T-DOM-02、T-EDIT-01、T-DEMO-01，新增对称识别与晶胞转换用例。

## 需求与当前事实

SDK 已能以晶胞、源原子和明确的对称信息创建周期快照，并展开等价位置。工作台可编辑已有晶胞并显式重置为 P1。缺少从空白创建晶体的工作台入口，以及按原子坐标识别空间群、标准化晶胞和提取原胞的工具。对照 [BIOVIA Visualizer](https://www.3ds.com/fileadmin/PRODUCTS-SERVICES/BIOVIA/PDF/materials-studio-visualizer.pdf) 和[当前 core API](../../api/core.md#晶胞与源结构)。

## 验收条件与实施步骤

1. 工作台可从空白输入晶胞、元素、分数坐标及可区分 setting 的空间群，预览对称展开结果后创建文档。非法晶胞、不兼容的对称和未消除的 setting 歧义须有诊断。
2. 定义空间群识别的输入、长度和角度容差、元素与占位约束。结果提供可复核的空间群 setting、对称操作和等价位点，无法在给定容差下确定时返回诊断。
3. 提供标准化晶胞和原胞转换，明确基变换、原点偏移、原子及显式键的来源映射。将识别、预览与应用分开，应用到当前文档时可一次撤销。
4. 对照独立晶体对称实现和已知空间群样例，覆盖多 setting、特殊位置、坐标扰动、非正交晶胞、部分占位及原胞转换。用 demo 验证从空白创建和转换后的导出。
