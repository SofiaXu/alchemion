状态：未开始。需求与验证：新增计算结果图层，复用 R-001、R-014、R-019、R-020、R-028，沿用 T-VIEW-01、T-VIEW-03、T-VIEW-04、T-RUN-01、T-PKG-01、T-DEMO-01，新增图层组合与性能用例。

## 需求与当前事实

当前 viewer 支持测量、配位多面体、第一布里渊区及 PNG，视图配置保存相机和显示选项。公开接口还缺通用结果图层及其保存恢复、拾取和资源管理。图层使用[已导入并配准的计算结果](../2026-11-04-calculation-result-import/README.md)。见[现有 PNG 与视图契约](../../api/viewer.md#png-与可移植视图)。

## 验收条件与实施步骤

1. SDK 与工作台支持添加、更新和移除独立图层。结构与多图层同场显示，可按层开关并调整适用的透明度、阈值、色标及顺序。拾取返回结果标识、对应帧、坐标或源原子和物理量单位，保持现有原子、键和测量拾取路径。
2. 图层绑定结果标识、结构和帧。文档切换、编辑或换帧时重新检查相容性，失配图层标明原因并暂停显示。新图层在有效几何提交到完整帧后报告可显示。图层设置与结构编辑历史分开。
3. 复用浏览器 Worker 处理大文件解码和图层几何，区分请求、文档修订、结果和图层。并发图层各自更新，支持取消、过期丢弃和资源释放。分别为文件、网格样本、三角面、轨迹帧及 GPU 资源定义预算和超限诊断。
4. PNG 包含可见图层与有单位的图例。版本化视图配置保存图层参数与数据引用，恢复时核对所需文件，缺少或失配时可重新关联。用多层、透明图例、快速换帧、迟到回复、取消和重复销毁的浏览器场景验证，并用真实 tarball 检查消费者入口。
5. 基础图层可用后，与[体数据计划](../2026-11-04-volumetric-field-overlays/README.md)联合验收首条完整路径。导出结构和映射，导入 VASP 静态或松弛计算对应的结果结构及电荷密度，开启等值面与切片，导出带图例的 PNG。编辑结构后验证旧图层的失配状态。
