# 聚合物构建

状态：未开始。需求与验证：新增聚合物构建需求，复用 R-005、R-017、R-018 的模型和事务，沿用 T-FMT-02、T-EDIT-01、T-DEMO-01，新增聚合物拓扑用例。

## 需求与当前事实

现有分子模型可保存展开后的原子与显式键，MOL 格式范围未包含聚合物或 Sgroup 语义。目标是按重复单元生成指定链长的均聚物、嵌段及随机共聚物，并支持端基、支链和树枝状构型。对照 [BIOVIA Visualizer 的聚合物构建工具](https://www.3ds.com/fileadmin/PRODUCTS-SERVICES/BIOVIA/PDF/materials-studio-visualizer.pdf) 和[当前格式范围](../../product.md#格式支持矩阵)。

## 验收条件与实施步骤

1. 复用[分子片段拼装](../2026-11-04-molecular-sketcher/README.md)的连接逻辑。定义内置和自定义重复单元的头尾、支化连接点、键阶、立体与端基规则。
2. 支持按指定序列或链长构建均聚物、嵌段及随机共聚物，并保存实际序列和随机种子。用支化连接点构建支链及树枝状拓扑，检测连接点冲突与预算超限。
3. 生成可编辑的显式分子快照，保存单元到原子的来源及初始构象参数。预览原子数与实际组成，说明导出显式结构时哪些聚合物信息无法表达。
4. 用短均聚链、已知双嵌段、固定种子的随机序列及支化样例验证连接拓扑、组分、端基和来源映射。用 demo 验证创建或提交后可导出。
