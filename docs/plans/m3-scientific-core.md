# M3：科学核心与领域不变量

状态：未开始。
需求：R-001、R-007、R-008、R-009、R-012、R-013、R-014、R-016、R-022；为 R-017/R-018 提供身份和校验基础。
测试：T-DOM-01、T-DOM-02、T-DOM-03、T-DOM-04、T-DOM-05、T-DOM-06、T-DATA-01；模块隔离由 T-PKG-01 辅助验证，性能最终关卡为 T-PERF-01。

## 目的与可见结果

SDK 消费者可以在不加载 viewer、DOM 或 Worker 的条件下创建和校验周期/非周期结构，转换坐标，计算对称/邻胞实例、几何邻接、距离/角/二面角、倒易晶格及第一布里渊区。结果具有明确单位、稳定身份和来源，可用于后续格式、运行时和显示实现。

本阶段不交付文件编解码、编辑历史管理器或浏览器交互；这些分别由 M4/M5 承担。M3 必须提供它们所需的纯数据和校验接口，不能提前把 viewer 或命令调度放入核心。

## 实施步骤

1. **建立参考和最小领域类型。** 按领域规范定义周期/非周期结构、稳定 AtomId/BondId、显式坐标、晶胞、化学属性、来源和诊断。周期键端点包含源 AtomId、对称操作 ID 和整数平移，不能只记录源 AtomId。对输入复制/快照隔离；校验重复 ID、悬空键、非法坐标、占位及晶胞。稳定 ID 与显示标签分离，序列化后仍可恢复身份。建立解析小体系和独立参考 fixture；在目标证据文件 `docs/evidence/m3-scientific-reference.md` 记录参考来源、生成程序/工具版本及输入，禁止用生产算法生成预期值。
2. **实现唯一晶胞数学。** 采用列向量矩阵、Å/度和 2π 倒易约定，提供参数↔基矢、体积、正逆坐标转换和病态判定。文件给定体积不能成为变换的独立输入真值。以立方、正交异长、单斜、三斜及接近退化的参数验证；检查往返残差与有限数值，不依赖旧公式复制。
3. **校验科学数据。** 对元素/共价半径、空间群操作及已有键价表逐项登记来源、版本和可复用范围。先验证再迁入；来源未核实的表不得作为权威默认值。价电子、形式电荷、氧化态拆分；参数索引须保留价态/来源区别，不能按元素对覆盖。键价数据若仅保留为公开参考数据，也要通过完整性检查，不顺带新增未批准的键价计算产品功能。
4. **实现对称与派生实例。** 用限定仿射语法解析有理数操作，验证整数旋转矩阵和来源 setting；对称后再平移。实现单胞归一化与原始平移追溯、邻胞去重、特殊位置去重和 fraction/bond cutoff。不同源原子永不因位置相同而合并；派生实例具有可逆映射和确定排序。输入缺失/歧义对称信息时按领域规范诊断，不猜 setting。
5. **实现确定性成键。** 显式键与推断键区分，规范化周期端点/平移；采用可追溯共价半径及默认阈值、对称的元素对规则。候选范围覆盖非正交晶胞和必要多层平移；采用空间索引或等价邻域方法。先实现完整重算作为行为真值；如添加增量接口，必须以相同结构序列对照完整重算，不复制另一套科学规则。
6. **实现测量与倒易/BZ。** 按领域规范计算实际显示位置的距离、角与有符号二面角；退化输入返回诊断。实现 `B=2π(A⁻¹)ᵀ` 和具有完备性判据的 BZ 半空间算法，保留科学多面体面关系；达到资源预算仍未收敛时明确失败。简单立方和正交胞使用解析参考，非正交胞用独立参考生成方法交叉核对，不能只比较同一实现的不同调用入口。
7. **收敛公共接口和证据。** 仅导出已具备验证的核心类型/函数，不输出引擎对象或格式耦合类型；为 M4 交付纯校验、源身份及派生输入输出。运行单元、类型、lint、格式和构建检查；将实际命令、环境、退出码及科学残差摘要记录于目标文件 `docs/evidence/m3-scientific-core.md`，同步本计划和交接。

## 验证与完成条件

| 场景      | 具体输入与预期观察                                                                                                                        |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| T-DOM-01  | 正交、单斜、三斜及退化晶胞；坐标往返、体积、矩阵列向量与单位符合领域容差；角度未转弧度、体积不一致及病态输入均被覆盖。                    |
| T-DOM-02  | 恒等/反演/分数平移、特殊位置、源坐标在单胞外、重复邻胞请求、单轴邻胞、cutoff 边界和不同源重叠位点；副本数量/位置/来源正确，重复计算确定。 |
| T-DOM-03  | 原子数组多种排列、阈值边界、未知半径、显式多键和跨周期键；输入顺序不影响结果；大候选不依赖盲目 N² 扫描；增量接口存在时与完整重算等价。    |
| T-DOM-04  | 解析距离、0°/90°/180°角、±90°及 180°二面角、镜像/反向顺序和重合/共线点；范围、符号与无定义诊断正确。                                      |
| T-DOM-05  | 验证 `AᵀB=2πI`；解析立方体及非正交 BZ；顶点满足半空间、体积为 `(2π)³/V`，有限枚举不足和预算失败不能返回伪成功。                           |
| T-DOM-06  | 同名原子、序列化/复制、重合位点、派生实例的正逆映射；ID 唯一，映射回正确源，生产计算不改调用者快照。                                      |
| T-DATA-01 | 每项正式采用数据有来源/版本和覆盖检查；重复参数不会覆盖消失；空间群 setting 与元素属性的语义可复核。                                      |

独立参考至少包含解析解与不调用生产代码的计算流程。矩阵参考可使用独立线性代数计算，BZ 可使用独立 Voronoi/半空间工具；在使用前将具体工具及固定版本写入参考证据，产物作为可审查 fixture 存入测试资产。工具只参与参考生成，不加入浏览器核心运行时。

M1 完成后，本阶段在仓库根目录运行 `pnpm test`（单次）、`pnpm typecheck`、`pnpm lint`、`pnpm format:check` 和 `pnpm build`，按质量规范解释结果。只运行核心相关测试进行迭代，收尾执行完整必需检查。`pnpm test:package` 用于核对核心导出与消费者隔离；科学性能检查通过 `pnpm bench` 的相关场景采集，最终万级交互关卡由 M6 完成。

关卡：上述科学用例通过且独立参考证据可复核；数据来源不明项没有进入默认科学路径；核心没有浏览器/引擎耦合；M4 能直接使用核心接口而不引用内部实现。任何失败或未运行检查都保留原状态，不能以构建通过替代科学验收。

## 中断与恢复

每次停止前记录已实现的接口、通过的测试和仍失败的案例，更新 [交接记录](../handoff.md)。下次先检查 Git 状态及目标证据文件，再运行当前失败用例；不要重建已经验证的参考 fixture 或覆盖他人改动。

未完成的算法不得作为已完成公共能力暴露；部分提交可保留内部实现并明确尚缺关卡。不为维持旧 API 建立临时正式适配层。接口发生必要变化时同步架构、领域规范和 M4 计划，避免后续会话依据过期类型实施。
