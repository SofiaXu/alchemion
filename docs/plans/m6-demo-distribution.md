## 实施步骤

1. **完成独立演示应用。** demo 只导入 `alchemion/core`、`alchemion/formats`、`alchemion/viewer`，不引用内部文件或引擎私有对象。提供有来源的内置晶体/分子样例、本地文件导入、block/版本选择及错误/警告呈现。样例资源随 demo 构建携带，不依赖外部数据库在线请求；无 WebGL2 的环境给出可理解的不可用状态。
2. **覆盖全部用户操作。** 以明确工具入口展示空间填充/球棍、配色、晶格/对称/邻胞/cutoff、倒易/BZ、选择回源、点坐标和距离/角度/二面角。提供增删原子、元素/坐标/晶胞编辑、undo/redo，并呈现当前坐标类型与单位。异步任务显示实际状态，可取消；过期回复和提交前的解析/源结构校验失败不能替换当前有效结构。源提交后的计算/渲染失败保留有效源并呈现可恢复 error，不把旧帧当成新帧 ready。
3. **打通格式与损失反馈。** UI 的可导出格式/版本与产品矩阵一致，包括 CIF1/2、MOL V2000/V3000 和周期 POSCAR。CIF 多 block 显式选择；MOL 默认 V3000，V2000 显式选择且超限拒绝，周期结构导出须有显式有限快照；POSCAR 无晶胞或部分占位拒绝。不可表达的科研语义默认 error；调用者通过显式选项接受具体损失后才能输出并附 warning，已有明确选项不再重复确认。重新导入自家导出产物验证语义，同时保留独立参考测试。
4. **验收真实分发边界。** 从构建目录 pack SDK，检查 tarball 文件白名单、exports、声明、许可证和必要数据署名。隔离消费者只安装 tarball，通过公开子路径使用 SDK；构建静态浏览器应用并在独立服务下验证 Worker/资源 URL。覆盖开发与生产构建，消费者不得使用仓库根 alias 或隐藏全局引擎依赖。`core`/`formats` 导入不得创建场景或 Worker，viewer 创建/销毁与多个实例符合契约。
5. **完成来源与清理。** 对照 T-DATA-01 核验 SDK、demo、fixtures 的实际内容，完成来源不明资产的替换或排除和必要署名。清除旧根源码/调试入口、CJS/兼容别名、内联 Worker 残留、落选引擎、临时 spike 和重复正式实现；保留有价值且有来源的测试资产。根据最终依赖删除无用途的包并重锁。历史缺陷通过新测试解释，不保留旧代码作为兼容层。
6. **定向验收与最终性能复验。** 固定Node/pnpm，执行冻结安装、构建、类型、改动lint/格式及文档链接；不默认运行`pnpm check`或历史完整套件。新增取消契约对应controller单元及受影响viewer浏览器场景；新demo用户闭环和真实tarball分别运行三个浏览器，开发模式仅Chromium验证Worker/编辑/导出差异。普通验证默认4进程、无自动重试，资源允许可升8；仅失败或修复影响项复验并记录理由。最终正式包复用现有采集器，GPU独占串行完成两模式各三轮10k原子/20k键、1920×1080/DPR1关卡，包含端到端、体积及20轮释放。Ubuntu定向复验用于平台路径/换行/Worker差异。
7. **交接正式 API 与维护入口。** README 使用真实可运行命令和公开 API 示例，文档中的历史源码链接指向迁移后的对应位置并注明历史基准；删除不再成立的临时说明。建立从需求→场景→证据的最终对照，更新选型/架构 ADR、阶段结果与 handoff。后续会话应能仅凭仓库开始新增功能和修复问题。

## 中断与恢复

每次恢复先核对 Git 差异、入口条件和已生成证据。隔离消费者的临时安装产物可以在确认路径后重新生成；SDK/demo 源码、来源记录和他人改动不能作为“清理缓存”删除。

清理旧实现前先定位正式替代路径、覆盖测试和数据来源，分批移除并运行受影响检查。若回归失败，保留失败证据，修复正式实现；不要通过恢复兼容入口绕过新契约。依赖变化后重新冻结安装和 pack，防止复用过期 tarball。没有硬件性能条件时可完成其他验收，但 T-PERF-01 保持未运行，M6 不标完成。

## 发现（Surprises & Discoveries）

只读核查发现：demo仍是M5最小按钮宿主；viewer缺少保留源/历史的主动取消及重算入口；当前CI漏删除diff，check默认全量单元且浏览器仍指历史宿主；tarball缺严格根白名单/VDW复核。以上是本轮新增实现与定向测试的具体依据，后续实际结果见下文。

2026-10-30实施首轮：新增cancel/recompute已通过controller12/12和@m6-runtime三浏览器3/3（maxWorkers4、实际3场景，无重试），SDK构建通过。demo build、首次根tsc、demo lint、冻结安装和31文档链接通过。生产demo首轮9/12，三个分子场景在测角阶段缺少结果；保留截图/trace，正在核对相机投影与拾取。package首次辅助编译因嵌套cwd失败，业务尚未运行；改用绝对输入路径后浏览器首轮2/3，Firefox导入前RAF归属待查。开发Chromium1/1通过。未扩大到历史全套。格式化命令误包含.gitignore导致该工具退出1，其余目标已格式化；最终只读格式检查将排除无解析器的.gitignore。

分子失败已单次诊断：默认沿Z的视角经15°旋转后，N原子中心投影实际命中N–S键（不是原子）。保留原坐标、科学预期及全部测量断言；demo改为三分量斜视方向，仍使用SDK自动fit。仅失败分子三浏览器复验3/3通过，首轮其余9项未重复。
