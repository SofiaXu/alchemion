## 目的与可见结果

SDK 消费者通过 `alchemion/viewer` 创建独立 viewer，显示全部目标结构效果，选择/拾取/测量并编辑源结构、撤销重做；快速加载、清空和销毁不会提交旧结果或遗留资源。所有正式显示只使用 M2 获选引擎，科学计算复用 M3，编辑历史与异步协议复用 M4。

## 实施步骤

1. **实现浏览器门面与资源边界。** 在目标 SDK viewer 内组织控制器、交互与获选后端，遵守架构的 `Viewer` 契约。创建自有 canvas，观察容器尺寸，使用 WebGL2；提供明确的不支持/上下文丢失诊断。公开 API 使用本库类型，不暴露引擎场景、mesh 或相机。订阅立即提供当前状态，clear/dispose 行为与状态转换由同一控制器管理。
2. **连接 RenderSnapshot。** 接入 M4 的 requestId/documentId/revision、取消/错误/超时协议；只渲染当前有效文档与修订，分帧过程也可失效。完整提交后才 ready；被取消/销毁的 Promise 以 AbortError 结束。提交前解析/结构校验失败保留原文档/历史；接受有效源后派生或渲染失败则保留新源和 error 状态、Promise reject，不发 ready。快照实例 ID 映射到源原子 ID、对称操作与晶胞偏移；显示键绑定正确实例。多个 viewer 使用各自状态、Worker 和资源，不使用共享可变源结构。
3. **完成全部显示能力。** 实现空间填充、球棍、元素颜色及配置、晶格/邻胞/对称显示与裁剪、自动成键、倒易晶格和第一布里渊区。球棍使用成键结果，不在 renderer 重新推断键；倒易与布里渊区使用核心生成的几何，不能复制科学公式或把原型 CSG 当科学真值。显示开关原子性更新，切换后旧辅助资源移除；性能显示为可选视图，不触发科学重算。
4. **相机、拾取和测量。** 实现居中、轨道旋转、缩放及有限数值参数；选择、点坐标、距离、角度、二面角模式互斥。原子与键分别返回可区分的选择事件和正确源映射，晶格/测量辅助图形不冒充原子；派生原子实例同时返回源 ID。坐标拾取调用核心逆变换；测量使用明确选择顺序和单位，退化几何返回领域诊断。切换模式/加载/清空重置临时选择与测量图形。
5. **接入编辑和历史。** 原子增删、元素/坐标修改、晶胞修改调用 M4 命令；派生实例编辑源原子，晶胞编辑保留分数坐标。输入及读取快照隔离；一次批量操作对应一个历史事务，历史默认 100 条且可配置，失败/空操作不入历史。undo/redo 恢复稳定 ID 并递增修订，显示/相机/测量不污染历史；load 更换 documentId，load/clear 重置历史与选择。结构命令串行执行不丢弃，latest-wins 仅用于派生计算；失败命令不可部分提交。
6. **完成销毁与恢复。** clear 失效任务、清空结构及辅助资源；dispose 幂等，取消渲染/RAF/Worker、移除监听/观察器/自有 canvas，结束待决调用并清理订阅。上下文恢复使用当前有效快照重建；失败给出可销毁重建诊断，不能切到未验收后端。以“创建—加载—交互—清空—销毁”循环验证资源归零。
7. **维护正式消费者与证据。** 用 ESM 子路径消费构建后的 viewer；浏览器场景覆盖全部产品模式与事件，不只 mock renderer。记录功能截图、异步顺序和计数；重跑固定 10k/20k 基准，确认接入科学/历史/交互后的预算。正式 demo 留给 M6，M5 的测试宿主只服务验收，避免又形成第二套产品实现。

## 中断与恢复

先核对当前计划、M2 决策、M4 实际接口和 `git status --short`，不要根据旧 Babylon 编辑器猜测当前后端。记录最后通过的测试与未完成模式，保留其他会话改动。

异步/资源失败先保留最小复现与修订/资源计数，再从单实例小结构逐步恢复到完整基准；不得通过关闭过期检查或跳过 dispose 解决。因 M2 方案不能满足正式集成预算时记录证据，回到选型决策评估，不私自加入第二后端。新结构/图形实现改变画质或基准输入时使旧性能报告失效并重跑。
