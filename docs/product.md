# 产品规范

状态：M0 确定的新版目标，尚未实现。更新时间：2026-10-29。现有实现事实见 [现状审计](baseline.md)，阶段进展见各执行计划和 [当前交接](handoff.md)。

## 产品定位与交付边界

Alchemion 为科研软件开发者提供可嵌入的浏览器 TypeScript SDK，并提供独立 demo，使用户能够导入晶体或分子、检查三维结构、测量、进行基础编辑并导出文件。SDK 是正式产品，demo 是独立消费者和完整交互验收入口；demo 不依赖未导出的 SDK 内部接口。

目标运行环境为现代桌面 WebGL2 浏览器，以扩胞后 10,000 个原子显示实例验收性能。Node.js 只用于开发和验证；本轮不建设后端、账号、云同步、移动端专属界面、量子化学计算或力场优化。渲染引擎由 M2 对照验证后决定，不能直接沿用旧实现视为定案。

新版允许重设公开 API、类型、目录和产物；不提供旧 API 适配、弃用别名或旧实现分支。业务能力、科学数据和旧测试须经重新验证后复用。此政策不影响新版仍须遵守其声明支持的文件格式标准。

## 格式支持矩阵

下表区分文档语法能力与结构模型能力。能够读出文本并不等于能够无损表达其中所有科学语义。除明确列出的字段外，不以“支持该格式”推导出完整字典、反应或聚合物支持。

| 格式 | 读写范围 | 映射到领域模型的字段 | 明确边界 |
|---|---|---|---|
| CIF 1.1 | 读写合法数据项、loop、多 block、注释、引号/分号文本及标准允许的 save frame。 | 晶胞长度/角度；分数或可转换的笛卡尔坐标；原子标签、元素、占位；等方 U/B 位移参数；空间群标识与仿射对称操作；上述数值的不确定度。 | 不实现宏分子 mmCIF 字典映射、磁对称、非公度调制或完整几何/键字典。 |
| CIF 2.0 | 上述语义；增加 Unicode、三引号、列表和表等 CIF2 文档语法。 | 与 CIF1 相同的晶体字段；支持本规范列明的传统标签及等价 dotted 标签。 | CIF2 语法扩展不意味着自动支持所有 DDLm 字典。CIF2 独有值不能悄悄降级为 CIF1。 |
| MOL V2000 | 单个分子的 V2000 molfile 读写。 | 元素、Å 笛卡尔坐标、形式电荷、同位素、自由基、原子映射号；单/双/三/芳香键及可表示的显式立体标志；标题和注释。 | 原子/键数不得超过各 999，其他字段也须可由 V2000 表示；不拆文件、不截断、不自动改版本。 |
| MOL V3000 | 单个分子的 V3000 molfile 读写，包含合法续行及非连续记录编号。 | 与 V2000 相同的基本分子语义；正确解析 atom/bond block 与相应属性。 | 不实现查询原子/查询键、反应、聚合物/Sgroup、R-group 或增强立体分组语义。 |
| POSCAR | 仅导出有有效晶胞的结构，采用 VASP5 元素名/数量行、缩放因子 1.0 和 `Direct` 坐标。 | 晶胞基矢、按元素分组的全部满占位源原子；输出顺序与数量一致。 | 不提供 POSCAR 导入；不推断真空盒、不展开部分占位、不输出速度或未经建模的约束。 |

CIF 晶体字段的最低映射如下；标签大小写不敏感，传统 `_category_item` 与列出的 `_category.item` 形式映射为相同含义，同义字段冲突时报告错误。

| 字段组 | 必须支持的语义 |
|---|---|
| 晶胞 | `cell_length_a/b/c`、`cell_angle_alpha/beta/gamma`；对应 dotted 的 `cell.length_a/b/c`、`cell.angle_alpha/beta/gamma`；`cell_volume`/`cell.volume` 用于交叉检查，实际体积由晶胞推导。 |
| 原子 | `atom_site_label`、`atom_site_type_symbol`、`atom_site_fract_x/y/z`、`atom_site_Cartn_x/y/z`、`atom_site_occupancy` 及其 `atom_site.*` 等价形式。分数与笛卡尔两组都存在时必须相互一致。 |
| 位移 | `atom_site_U_iso_or_equiv`、`atom_site_B_iso_or_equiv` 及 dotted 等价形式；明确 U/B 的定义和转换。不把各向异性参数误当作等方值。 |
| 对称 | `space_group_IT_number`、`space_group_name_H-M_alt`、`space_group_name_Hall`、`space_group_symop_operation_xyz`；旧字典的 `symmetry_Int_Tables_number`、`symmetry_space_group_name_H-M`、`symmetry_space_group_name_Hall`、`symmetry_equiv_pos_as_xyz`；对应 dotted 形式。空间群号不能独自消除 setting 歧义。 |
| 缺失与精度 | `.` 与 `?` 保持不同；数值与括号不确定度分别保存。必需坐标/晶胞不能用缺失标记替换后继续计算。 |

格式行为统一如下：

- CIF2 以文件标准版本标识 `#\#CIF_2.0` 识别；没有 CIF2 标识的输入按 CIF1.1 校验，不以扩展名或 Unicode 字符猜测升级。输出明确选择 CIF1/CIF2，CIF2 输出包含标准版本标识。
- CIF 文档层返回全部 block。晶体结构映射要求有效晶胞，恰有一个 block 时自动选择；存在多个 block 而调用者未提供名称或从 0 开始的索引时，返回包含候选项的选择错误。无 block、重复 block 名、未知选择或选定 block 不含所需晶体字段均有具体诊断，不默默读取第一项或跳过不适用 block。
- MOL 默认输出 V3000，V2000 需要显式选择。对周期结构导出 MOL 需要调用者先明确请求有限快照，并指定源原子或选中的显示实例集合；将快照坐标转为 Å 笛卡尔坐标。晶胞、周期性、空间群、占位等不能表达的信息必须进入损失诊断，不隐式生成扩胞快照。
- POSCAR 拒绝无晶胞、空结构、非满占位或占位未知的原子，显式接受损失也不能绕过这些前提。元素分组顺序按源原子中首次出现的元素确定；保留原子标签、显式键、空间群和位移等无法表达的信息时须报告损失，不能把格式自身无法表示的信息写成伪字段。
- 显式科学信息无法表达时默认拒绝导出；只有调用者显式接受该次损失后才生成文件，同时保留逐项诊断。推断键和显示实例属于可重算派生结果，不要求自动写入格式。标题、注释等非科学注记的省略也需警告，但不阻塞导出。
- 读取不支持的科学构造时须指出所在记录/标签及未支持能力，不能无提示地降为普通原子或单键。低层 CIF 文档语法可保留未映射类别；结构编解码的诊断须列明未映射科学类别，不承诺任意原文无损编辑。

## 交互、编辑与完成定义

viewer 对源结构及其派生显示结果负责；选择、坐标和测量都以用户实际点中的显示实例为准。编辑实例时，通过逆变换修改源原子；所有对称和邻胞副本在同一结构修订下重新派生。晶胞编辑保留源原子的分数坐标，更新笛卡尔位置。科学细节以 [领域规范](domain.md) 为准。

demo 必须具备文件导入/block 选择、格式版本与导出范围选择、显示模式和晶格/倒易/BZ 开关、选择与测量、基础编辑、undo/redo、状态与诊断展示。不能用仅有控制项或类型声明代替功能；未完成或失败的能力须真实呈现状态。

阶段完成须同时满足需求对应行为、[质量规范](quality.md) 中的验证及可复核证据。M0 文档完成不代表上述运行能力已通过。新格式、服务器能力、完整化学推理或更大性能目标属于需求变更，应先更新本文件及相关领域/架构决策。

- [VASP POSCAR 说明](https://vasp.at/wiki/POSCAR)：用于 POSCAR 基矢、元素计数、缩放因子和坐标模式。
