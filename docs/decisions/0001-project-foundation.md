# ADR 0001：项目目标与重构基础

日期：2026-10-29。状态：**Accepted（批准新版目标，未表示实现或验证完成）**。

## 背景

现有代码是 TypeScript/Babylon.js 库和调试页面，缺少项目文档、稳定模块边界及完整功能验证。静态审计发现科学坐标、实体身份、异步一致性和生命周期风险，不能以现有行为作为新版兼容标准。历史证据及基准提交见 [baseline.md](../baseline.md)。

用户要求全面重构，不兼容旧版，并先建立可供后续 Codex 会话接管的文档。已确认的产品取向、功能范围和工程边界以本决策及 [产品规范](../product.md) 为准。

## 决定

- 交付浏览器 SDK 与独立 demo；使用 TypeScript、pnpm workspace，保留一个 SDK 包 `packages/alchemion` 与一个应用 `apps/demo`。运行目标为现代桌面 WebGL2，Node.js 仅为开发工具。
- SDK 采用 ESM only，正式子路径为 `alchemion/core`、`alchemion/formats`、`alchemion/viewer`。科学核心和格式不依赖引擎、DOM、Worker 或构建器专用查询；引擎对象不进入正式公开 API。
- 新版覆盖现有及已声明能力：科学结构、晶胞/对称/邻胞/成键、空间填充与球棍、颜色、晶格/倒易晶格/第一布里渊区、选择/坐标拾取/距离/角度/二面角、基础编辑及撤销重做。格式为 CIF1/CIF2 晶体读写、MOL V2000/V3000 读写、周期结构 POSCAR 输出。字段和损失边界由产品规范明确。
- 性能主场景为**扩胞后** 10,000 个原子显示实例；测试以固定 20,000 条显示键、1920×1080、DPR 1 控制条件，预算与设备记录见 [quality.md](../quality.md)。这是待实测目标，不能将原子数理解为扩胞前数量。
- 渲染引擎由 M2 对照 Three.js/Babylon.js 的同等原型、质量与性能证据决定；本 ADR 不选定引擎。最终仅维护一个正式后端，详见 [ADR 0002](0002-renderer-selection.md)。
- 周期结构使用分数坐标，非周期结构使用 Å 制笛卡尔坐标；渲染使用笛卡尔坐标。稳定 ID、源/派生映射、输入快照、晶胞编辑保留分数坐标、事务历史和可取消版本化计算是架构约束。
- 允许更换旧 API、目录、配置、测试与产物，不增加旧接口适配、弃用别名或第二份正式实现。旧数据和断言逐项验证来源及科学意义，不能无条件继承。
- 先完成 M0 接管文档，再按 [路线图](../roadmap.md) 的阶段关卡实施。根 AGENTS、执行计划和交接记录是跨会话入口；事实、目标、待验证事项分开记录。

## 后果与边界

新 API 的消费者需要采用新版接口；不为旧入口提供迁移兼容代码。保留正确的业务需求和有来源的测试材料，不等于保留旧错误。

当前阶段仅增加文档，不升级依赖、不移动源码、不实现 workspace，也不宣称测试通过。M1–M6 的具体状态见对应执行计划；只有相应验证证据才能证明能力完成。运行时支持、浏览器矩阵、科学精度和性能结论不得由纸面架构推断。

M2 前唯一未定的基础技术选择是正式渲染后端；若实测不能满足既定预算，按选型计划记录阻碍并修订决策，不私自降低要求或选择未达标候选。

## 依据与维护

产品/架构依据是 2026-10-29 用户已确认的重构方向；科学约定见 [domain.md](../domain.md)，模块与接口见 [architecture.md](../architecture.md)。[OpenAI AGENTS.md 指南](https://learn.chatgpt.com/docs/agent-configuration/agents-md) 用于指令文件组织，[ExecPlans 指南](https://developers.openai.com/cookbook/articles/codex_exec_plans) 用于持续维护执行计划；这些资料不证明本项目已实现或通过验收。

改变本 ADR 的已接受目标须新增或明确替代决策，并同步产品、架构、路线图、计划与交接；不能仅修改某个实现计划使目标悄然漂移。
