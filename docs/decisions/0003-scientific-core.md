# ADR 0003：科学核心与历史消费者的分阶段边界

状态：Accepted。日期：2026-10-29。依据：用户批准的完整 M3 实施计划；运行验证另见阶段证据，不由本 ADR 预先宣称。

## 决定

`alchemion/core` 一次切换到纯数据科学 API。周期源使用分数坐标，非周期源使用 Å 笛卡尔坐标；原子、键、操作使用稳定字符串 ID，标签不充当身份。源快照复制并冻结，公开结果均可序列化。可失败操作返回 `ScientificResult<T>`，错误分支没有 `value`。

晶胞只以列向量基矢作为几何权威；参数、体积、正逆坐标和含 2π 的倒易基矢统一推导。报告体积与计算体积的差超过报告标准不确定度加领域数值容差时产生警告，返回值仍是计算体积。M4 负责从格式字面精度提取合适的报告精度；没有精度信息时使用零附加容差。

对称采用整数旋转和精确有理平移；显式操作优先，setting 歧义阻止扩展但不抹去基础结构。特殊位置只合并同源、同实际位置实例，并保存等价来源。显示键引用显示实例，周期规范端点保留源 ID、操作 ID 和整数平移。

M3 使用完整成键重算和空间索引，不建设增量规则。半径采用 Cordero 2008 经 periodictable 2.0.2 发布的表，C 为 sp3、Mn/Fe/Co 为低自旋；97–118 无半径，不能推断相关键。空间群使用 spglib 2.6.0 全部 530 Hall setting，不由 IT 号挑第一项。完整来源和许可随包提供，键价计算不进入产品范围，未使用且未核实许可的旧键价表删除。

第一 BZ 使用逐壳半空间裁剪和可证明的遗漏格矢下界；默认最多 64 壳/250,000 候选。尚未证明完备即耗尽预算时失败，不把近似结果作为成功返回。测量直接使用实际显示点，不隐式应用最小影像。

## 历史边界与后果

原 core 的旧模型、元素/空间群/配色和工具移到 `internal/legacy`，只供尚待 M4/M5 迁移的 formats/viewer 内部引用，不提供公开兼容入口或新旧模型转换器。旧 viewer 的重复科学公式仍是历史实现，不能作为新版科学真值。其尚未核实的数据继续登记于来源台账，不能因移动而标为完成。

M4 用新版快照和校验替换历史格式模型、实现事务与 Worker；M5 用唯一新版算法接入 Three viewer；M6 清除失去消费者的历史代码和数据。新 core 由 ES2022 类型检查、导入限制和真实 tarball 无 DOM 声明消费者验证边界。
