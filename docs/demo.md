# 晶体科研工作台使用指南

在仓库根按[开发指南](development.md)准备环境后执行 `pnpm dev`，打开输出地址。首屏载入正交教学晶体并显示晶胞。工作台通过三个正式 SDK 子路径工作，中央为三维视图，左侧按准备、研究和输出组织七个工具，检查器显示选择回源、拾取点、测量与诊断。在较窄的桌面窗口中可在视图下方展开检查器。WebGL2 不可用时可继续阅读教程、浏览示例说明和查看来源许可。

内置结构和计算结果是项目自产、MIT 许可的教学数据。样例和来源声明随静态产物打包。首次语言按浏览器选择中/英，可在语言控件切换并保存。控件、帮助和状态随语言切换，SDK 的诊断代码、原始说明和定位保持原文。

## 示例库和跟做教程

通过顶部“示例库”或“教程”进入。教程可打开相应工具或显式填入预设，预览、应用和导出均由用户触发。浏览教程保留当前文档。载入会替换当前结构的示例，或打开结果帧时，若有撤销或重做记录，工作台会先提示确认。

| 教程              | 可核对的结果                                                                |
| ----------------- | --------------------------------------------------------------------------- |
| 从 CIF 到倒易空间 | 从双 block CIF 选择倾斜晶胞，查看实例回源及第一布里渊区。                   |
| 分子测量和出图    | 四原子几何的距离、角度、有符号二面角依次为 3 Å、90°、+90°，并可导出 PNG。   |
| 建晶、超胞和缺陷  | 单碳 P1 晶胞扩为两个源原子，替换其中一个并撤销。                            |
| 薄层与送算准备    | 选择 (100) 终止面，切割并固定底层，经预检导出 POSCAR。                      |
| 带端基的聚合物    | 两个乙烯单元加氢端基组成 C₄H₁₀，MOL 导出提示配方损失。                      |
| 浏览计算结果      | 从两帧教学数据查看等值面、切片及能量曲线，选能带 k 点后在布里渊区显示标记。 |

## 导入并检查结构

1. 在“导入”选择正交教学晶体、合成分子或双 block 合成晶体，点“载入样例”。也可选择本地 CIF/MOL/POSCAR 文件，或粘贴文本并选择相应格式后点“读取 / 导入”。POSCAR、CONTCAR 及 `.vasp/.poscar` 按文件名识别。
2. 观察识别版本。支持 CIF1/2、MOL V2000/V3000 和含 Selective Dynamics 的 VASP5 POSCAR。POSCAR 速度和缺元素行会明确诊断。
3. 多 block CIF 会显示候选。显式选择 block，再点“读取 / 导入”；不会默认读取第一项。内置晶体提供 `orthogonal` 和 `oblique`。
4. 检查右侧“导入诊断”。语法或源校验失败会保留当前文档、历史和显示；接受有效新源后，计算/渲染失败会保留新源并显示可恢复错误。

顶部显示源类别、源原子数、修订及就绪/计算/错误等状态。源原子数不等于对称和邻胞展开后的显示实例数。

## 显示与相机

在“显示”选择空间填充或球棍，设置原子倍率和 Å 制球、键、缺失显示半径，再点“应用显示设置”。元素样式可覆盖颜色、空间填充半径及球半径；“恢复默认元素样式”删除该元素的覆盖。缺失范德华半径使用带诊断的视觉兜底，不改变科学半径或成键。

周期源可开关晶胞/晶格方向、对称等价位置、倒易晶格和第一布里渊区。倒易/BZ 位于独立 Å⁻¹ 小视窗，随主朝向变化；分子没有晶胞，相应图形隐藏并给诊断。

“邻胞偏移”每行一个整数三元组，例如 `1 0 0`；留空仅中心晶胞。分数截取填写非负 `x y z` 边距；成键端点截取保留主胞原子与其直接成键端点，不无限扩展。成键开关控制几何推断，显式源键仍保留。精确规则见[领域规范](domain.md)。

拖动视图旋转，滚轮缩放；“适配结构”“旋转 15°”“放大”“缩小”提供显式控制，相机详情可展开查看。显示设置和相机变化不进入结构撤销历史。“性能信息”是显示辅助，正式性能门槛与采集方式见[质量规范](quality.md)。

## 选择、点坐标和测量

在“测量”选择工具并点“启用工具”，再在三维视图中操作：

| 工具                | 操作与结果                                                                                                |
| ------------------- | --------------------------------------------------------------------------------------------------------- |
| 选择原子或键        | 点击显示几何，在右侧查看稳定实例 ID、源原子、操作/整数偏移；键含显式或推断来源及两个端点。                |
| 框选源原子          | 左拖矩形贯穿选择投影中心；Shift 增选，Ctrl/Meta 切换。副本映射为源集合，全部可见同源副本共同高亮。        |
| 拾取表面 / 视平面点 | 点击几何返回表面点，空白返回经过相机 target 的视平面点；右侧明确来源与 Å 笛卡尔坐标，周期源另有分数坐标。 |
| 距离                | 按顺序点击 2 个原子中心，结果为 Å。                                                                       |
| 角度                | 按顺序点击 3 个原子，中间点为顶点，结果为度。                                                             |
| 有符号二面角        | 按顺序点击 4 个原子，结果在 `(-180°,180°]`，共线等退化选择给诊断。                                        |

测量使用实际显示实例中心，不用表面交点，也不把跨邻胞选择缩回最小影像。切换工具或载入/清空文档会清临时选点；源修订后清测量，仍有效的实例选择会重新解析。

## 编辑源与撤销重做

“编辑”中的源原子表每页 50 行，显示源 ID、元素和源坐标。点表中 ID 或在视图中选择原子后，编辑字段跟随该源。周期坐标可显式选分数或 Å 笛卡尔；分子只使用 Å 笛卡尔坐标。

- “应用元素及位置”把两个字段作为一次事务提交；“增加原子”分配新的稳定 ID；“删除源原子”同时影响全部派生副本并清理关联显式键。
- 在视图选择一个原子实例后，填写“所选实例位置 x y z（Å）”，点“移动实例并回写源原子”。SDK 逆转该实例的变换回写源，随后全部关联实例重建；副本不成为独立源原子。
- 周期源可修改晶胞长度（Å）和角度（度），保持源分数坐标。与现有对称不相容时整个事务失败；需要降为 P1 时，明确勾选“在本次事务中显式将对称性重置为 P1”。分子不提供晶胞编辑。

一次提交对应一条历史；失败或空操作不增加历史。顶部“撤销/重做”恢复源与稳定 ID，修订仍递增；新编辑清 redo。载入新源或“清空文档”清历史。坐标、晶胞或参照原子的编辑可能清理失效测量不确定度/立体信息，右侧运行诊断说明变化。

### 多选、批量编辑与超胞

“编辑”顶部可按元素选择全部源原子，也可全选、清空或在视图框选；不受原子表当前页限制。批量平移显式选择分数坐标或 Å 笛卡尔坐标，替换使用元素控件，删除同时清理关联显式键。每个源只处理一次，一次撤销恢复整批。切换工具保留源集合；被删除后清除的选择不会随 undo 自动恢复。

周期源填写沿 a、b、c 的三个正整数倍数，点“生成超胞”。它完整展开源对称并生成可独立编辑的 P1 源，不受显示邻胞设置影响；一次撤销恢复原晶胞和对称。新副本有独立 ID，生成后可按元素/框选删除或替换来构建空位与替位。占位不随机实体化；无法可靠投影的周期键立体标志会明确阻止构建。

### 配位分析

选择一个或多个源原子，在“测量”的配位区域每行输入 `C O 2.5`，或带最小距离的 `C O 0.5 2.5`，单位 Å；同一无序元素对只能有一条规则。“分析所选中心”返回各源的确定中心胞代表、邻居来源/距离及几何配位数，可显示多面体。周期搜索不受屏幕邻胞或成键设置限制；计数不按占位加权。共面等退化情况保留邻居列表并给出诊断。

### PNG 与保存视图

“导出”底部可设置 PNG 像素宽高和透明背景，默认提供 3840×2160。输出包括科学图形、配位多面体和当前测量文字，不包括性能信息、选择高亮或框选矩形。尺寸受设备和 32 兆像素预算限制；导出中改变视图或文档会取消该次导出。

“显示”底部保存相机、显示和配位配置，可下载/导入版本化 JSON，也可保存、恢复、重命名或删除浏览器命名槽。相同名称的保存会覆盖该名称，重命名冲突明确拒绝。结构文件、历史、选择与瞬时测量不在视图配置内；恢复后针对当前选择重新计算配位。损坏或未来版本的存储保留原数据并降级为本页内存，配额/权限错误也会明确显示会话保存；JSON 仍可使用。迟到的文件读取不会覆盖较新的恢复操作。

## 结构建模

打开「建模」，在晶体与对称、表面与界面、缺陷、分子与聚合物、填充与纳米五组中选择工具，填写参数并按需展开高级选项。先预览组成、晶胞及诊断，再确认应用。勾选「作为新文档打开」会建立独立文档。对当前结构应用时可一次撤销。

查询终止面、叠层匹配或间隙后，点击候选可将索引或坐标带到构建表单。叠层、吸附和填充接受额外的本地结构文件。填充可用当前分子作为单一组分，也可按上传顺序为各组分设置数量或比例。选择基底填充时可使用当前周期结构，或为表单提供本地基底。构建薄层后可按底层层数或选区设置三个 Direct 标志并导出 POSCAR。

折叠式 JSON 入口支持复制当前表单配方、粘贴并填入表单、直接预览 JSON。含表单无法表达的元数据时，可保留并直接预览原配方。字段、坐标与单位见[建模 API](api/modeling.md)。

分子草绘支持从空白开始。取点会把 Å 坐标带到原子编辑，选择两个原子或输入它们的 ID 即可添加显式键。已有显式键可拾取并修改键阶或删除。片段、补氢与聚合物也走预览和应用。自定义片段提供快照和连接点。聚合物可用 `hydrogen` 等内置片段作为端基，MOL 导出时确认配方损失。

## 取消与恢复

计算或读取期间可点“取消任务”。未接受的请求失效；已经接受的源、修订和历史保留，失效显示清除，界面显示已取消。“重新计算”按当前源和显示选项恢复，不创建历史事务或新修订。取消不等于撤销已接受的编辑。

源接受后的计算/显示错误也保留源，先检查运行诊断，再调整输入或重新计算。没有源时不能重算；“清空文档”会清除源和历史。离开页面时工作台销毁自有 Viewer 并释放下载 URL。

## 预检、接受损失与导出

1. 选择目标格式。CIF 选择 1.1/2.0；MOL 默认 V3000，V2000 要显式选择；周期 POSCAR 无版本选项。
2. 周期源导出 MOL 时指定有限集合：填写源 ID（逗号或空白分隔，可用“选择当前全部源原子”），或在三维视图选择实例并逐个点“加入所选实例”。“清空实例集合”重置收集结果。源集合与显示实例集合表达不同输出范围，不自动扩胞。
3. 点“检查导出”，读取导出诊断。工作台补全可发现的科学损失；只存在可接受损失时提供“接受本次已列出的损失”。该确认只适用于当前源修订与选项，修改后必须重新检查。
4. 硬性格式限制不能接受绕过，例如 V2000 超限、周期 MOL 未选有限集合、POSCAR 无晶胞或非满占位。此时先修正输入或选择其他可表达的格式。
5. 生成文本后查看“导出预览”和可用的“导出原子映射”，再“下载文件”。CIF/MOL/POSCAR 均可“重新导入当前输出”，它会载入新文档并清历史。

格式支持与损失边界见[产品规范](product.md)和[formats API](api/formats.md)。界面“来源与许可”打开随应用生成的离线声明；数据追溯见[来源台账](data-sources.md)。SDK 集成从[快速开始](getting-started.md)继续，完整选项和生命周期见[viewer API](api/viewer.md)。

## 计算结果

1. 在“导出”中检查并下载 POSCAR，另存“下载 POSCAR 原子凭据”。保留该凭据与实际送算的 POSCAR。计算在 Alchemion 外完成。
2. 在“结果”中选择格式并导入本地文件。选择结果和结构帧，上传对应凭据并点“关联当前结构”。也可按结果顺序显式输入源原子 ID，或用“打开所选帧”建立新文档。
3. 选数据通道与图层类型。电荷密度可同时添加等值面和切片。为第二场着色或差分时，先将两份数据关联到同一帧。图层列表可调可见性、透明度、色标、阈值和顺序。用“拾取结果图层”读取坐标、数值及单位。
4. 用帧滑块、能量曲线或播放按钮浏览轨迹，选择“展开周期影像”检查连续运动。“返回源结构”退出预览并恢复编辑。跨结果结构对比须确认原子配对。
5. 在频谱上选择模式，调节振幅与相位。能带与 DOS 共用能量轴，选择 k 点后在第一布里渊区标记。费米面使用完整三维网格数据。
6. 在视图面板保存配置或导出包含可见结果图层及图例的 PNG。版本 2 配置可在重启后重新导入原文件、核对内容摘要并配准。结构修改会使失配图层暂停显示。

输入文件和版本化结果数据的具体子集见[结果格式契约](api/formats.md#计算结果读入)。
