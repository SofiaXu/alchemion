# 结构工作台使用指南

在仓库根按[开发指南](development.md)准备环境后执行 `pnpm dev`，打开输出地址。工作台通过三个正式 SDK 子路径工作，中央为三维视图，左侧为导入、显示、测量、编辑和导出，右侧显示选择/回源、拾取点、测量与三类诊断。运行需要桌面 WebGL2；不可用时界面显示原因。

内置样例是项目自产、MIT 许可的教学几何，并非实验结构；样例和来源声明随静态产物打包，无需外部数据库。首次语言按浏览器选择中/英，可在语言控件切换并保存；存储不可用时仍可使用。控件、帮助和状态随语言切换，SDK 的诊断代码、原始说明和定位保持原文。

## 导入并检查结构

1. 在“导入”选择合成分子或双 block 合成晶体，点“载入样例”；也可选择本地 `.cif/.mol` 文件，或将文本粘贴到“文件内容”并选择 CIF/MOL 格式后点“读取 / 导入”。
2. 观察识别版本。CIF1/2 和 MOL V2000/V3000 由文本识别，POSCAR 仅导出。
3. 多 block CIF 会显示候选。显式选择 block，再点“读取 / 导入”；不会默认读取第一项。内置晶体提供 `orthogonal` 和 `oblique`。
4. 检查右侧“导入诊断”。语法或源校验失败会保留当前文档、历史和显示；接受有效新源后，计算/渲染失败会保留新源并显示可恢复错误。

顶部显示源类别、源原子数、修订及就绪/计算/错误等状态。源原子数不等于对称和邻胞展开后的显示实例数。

## 显示与相机

在“显示”选择空间填充或球棍，设置原子倍率和 Å 制球、键、缺失显示半径，再点“应用显示设置”。元素样式可覆盖颜色、空间填充半径及球半径；“恢复默认元素样式”删除该元素的覆盖。缺失范德华半径使用带诊断的视觉兜底，不改变科学半径或成键。

周期源可开关晶胞/晶格方向、对称等价位置、倒易晶格和第一布里渊区。倒易/BZ 位于独立 Å⁻¹ 小视窗，随主朝向变化；分子没有晶胞，相应图形隐藏并给诊断。

“邻胞偏移”每行一个整数三元组，例如 `1 0 0`；留空仅中心晶胞。分数截取填写非负 `x y z` 边距；成键端点截取保留主胞原子与其直接成键端点，不无限扩展。成键开关控制几何推断，显式源键仍保留。精确规则见[领域规范](domain.md)。

拖动视图旋转，滚轮缩放；“适配结构”“旋转 15°”“放大”“缩小”提供显式控制，相机详情可展开查看。显示设置和相机变化不进入结构撤销历史。“性能信息”是显示辅助，正式性能门槛与采集方式见[质量规范](quality.md)。

## 选择、点坐标和测量

在“测量”选择工具并点“启用工具”，再在三维视图中操作：

| 工具                | 操作与结果                                                                                                |
| ------------------- | --------------------------------------------------------------------------------------------------------- |
| 选择原子或键        | 点击显示几何，在右侧查看稳定实例 ID、源原子、操作/整数偏移；键含显式或推断来源及两个端点。                |
| 拾取表面 / 视平面点 | 点击几何返回表面点，空白返回经过相机 target 的视平面点；右侧明确来源与 Å 笛卡尔坐标，周期源另有分数坐标。 |
| 距离                | 按顺序点击 2 个原子中心，结果为 Å。                                                                       |
| 角度                | 按顺序点击 3 个原子，中间点为顶点，结果为度。                                                             |
| 有符号二面角        | 按顺序点击 4 个原子，结果在 `(-180°,180°]`，共线等退化选择给诊断。                                        |

测量使用实际显示实例中心，不用表面交点，也不把跨邻胞选择缩回最小影像。切换工具或载入/清空文档会清临时选点；源修订后清测量，仍有效的实例选择会重新解析。

## 编辑源与撤销重做

“编辑”中的源原子表每页 50 行，显示源 ID、元素和源坐标。点表中 ID 或在视图中选择原子后，编辑字段跟随该源。周期坐标可显式选分数或 Å 笛卡尔；分子只使用 Å 笛卡尔坐标。

- “应用元素及位置”把两个字段作为一次事务提交；“增加原子”分配新的稳定 ID；“删除源原子”同时影响全部派生副本并清理关联显式键。
- 在视图选择一个原子实例后，填写“所选实例位置 x y z（Å）”，点“移动实例并回写源原子”。SDK 逆转该实例的变换回写源，随后全部关联实例重建；副本不成为独立源原子。
- 周期源可修改晶胞长度（Å）和角度（度），保持源分数坐标。与现有对称不相容时整个事务失败；需要降为 P1 时，明确勾选“在本次事务中显式将对称性重置为 P1”。分子不提供晶胞编辑。

一次提交对应一条历史；失败或空操作不增加历史。顶部“撤销/重做”恢复源与稳定 ID，修订仍递增；新编辑清 redo。载入新源或“清空文档”清历史。坐标、晶胞或参照原子的编辑可能清理失效测量不确定度/立体信息，右侧运行诊断说明变化。

## 取消与恢复

计算或读取期间可点“取消任务”。未接受的请求失效；已经接受的源、修订和历史保留，失效显示清除，界面显示已取消。“重新计算”按当前源和显示选项恢复，不创建历史事务或新修订。取消不等于撤销已接受的编辑。

源接受后的计算/显示错误也保留源，先检查运行诊断，再调整输入或重新计算。没有源时不能重算；“清空文档”会清除源和历史。离开页面时工作台销毁自有 Viewer 并释放下载 URL。

## 预检、接受损失与导出

1. 选择目标格式。CIF 选择 1.1/2.0；MOL 默认 V3000，V2000 要显式选择；周期 POSCAR 无版本选项。
2. 周期源导出 MOL 时指定有限集合：填写源 ID（逗号或空白分隔，可用“选择当前全部源原子”），或在三维视图选择实例并逐个点“加入所选实例”。“清空实例集合”重置收集结果。源集合与显示实例集合表达不同输出范围，不自动扩胞。
3. 点“检查导出”，读取导出诊断。工作台补全可发现的科学损失；只存在可接受损失时提供“接受本次已列出的损失”。该确认只适用于当前源修订与选项，修改后必须重新检查。
4. 硬性格式限制不能接受绕过，例如 V2000 超限、周期 MOL 未选有限集合、POSCAR 无晶胞或非满占位。此时先修正输入或选择其他可表达的格式。
5. 生成文本后查看“导出预览”和可用的“导出原子映射”，再“下载文件”。CIF/MOL 可“重新导入当前输出”，它会载入新文档并清历史；POSCAR 不支持重新导入。

格式支持与损失边界见[产品规范](product.md)和[formats API](api/formats.md)。界面“来源与许可”打开随应用生成的离线声明；数据追溯见[来源台账](data-sources.md)。SDK 集成从[快速开始](getting-started.md)继续，完整选项和生命周期见[viewer API](api/viewer.md)。
