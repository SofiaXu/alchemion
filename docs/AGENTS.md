# 文档维护规则

本目录继承根 [AGENTS.md](../AGENTS.md)。

- 正式文档描述当前可用能力和契约。观察注明日期与适用环境；目标、假设及待验证事项进入 [plan](plan/README.md)，不能写成既有能力。
- `product.md` 管稳定 R 编号与产品边界；`domain.md` 管科学语义；`architecture.md` 管模块边界；`api` 管公开接口；`quality.md` 管稳定 T 编号与验证方法；`development.md` 管命令和工具；`data-sources.md` 管当前资产来源与许可。避免重复维护事实。
- 文档使用仓库内相对链接。链接指向实际存在的文件或有效网页；尚未创建的目标路径使用代码文本。源码移动时同步修正引用。
- 科学与格式依据使用一手规范，说明用途。数据来源未知时注明待核实，不推断许可或捏造署名。
- 修改正式 API、科学约定或模块边界时同步相关正式文档与验证，不另存重复决策结论。
- 未完成任务遵守 [PLANS.md](../PLANS.md)。原始运行结果放忽略目录或 CI 附件；完成任务吸收有效内容后删除文件夹。
- 收尾检查链接和锚点、R/T 覆盖、命令状态、源码事实、旧路径残留与格式。只有实际运行且符合预期的检查才能记为通过。
